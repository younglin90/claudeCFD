## C++ conventions (follow `cpp/MIGRATION.md` + existing `eos.hpp`/`primitive.hpp`)

- **Header-only**, POD structs + enum tags, no virtual dispatch on hot paths.
- Every leaf math routine is a scalar function marked `CFD_ROUTINE_SEQ`
  (`acc routine seq` on device / no-op on host); array work lives in the
  caller's OpenMP/OpenACC loop. Per-cell / per-face scalar funcs + caller loop.
- **Bit-comparable clamps**: reproduce every Python guard EXACTLY.
  `np.maximum(x, 1e-30)` → `EOS::max2(x, 1e-30)`; `_EPS = 1e-30` throughout the
  5eq Python. Record each constant (below) and clamp identically.
- Reuse `cfd::EOS` (`eos.hpp`) and `cfd::PrimW`/`ConsU` + `cons_to_prim_W`
  (`primitive.hpp`). **Confirmed present** — see EOS/primitive reuse note.
- Each module gets a `test_5eq_<name>.cpp` asserting rel ≤ 1e-12 vs the matching
  `cpp/tests/5eq_ref/*.txt` file (same `check()` pattern as `test_eos.cpp`).
- Types: `double` only; `bool` masks → `std::vector<char>` or bitset in caller.
- The implicit acoustic linear solve is the ONE place needing a banded solver
  (Thomas / LAPACK `dgbsv`); everything else is stencil arithmetic.

## Module details

### M1 — Mixture sound speed + phase acoustic impedance Z
**`sound_speed.py:21-48`, `explicit.py:22-40`**. `_EPS=1e-30`.

Per-phase c² from analytic (p,T) derivatives (`phase_sound_speed_sq`):
```
pr2   = p / max(rho^2, 1e-30)
Θ_k   = (pr2*drhodp_T - dedp_T) / ( (e_T - pr2*drhodT_p) if |den|>1e-30 else 1e-30 )   # den = dedT_p - pr2*drhodT_p
K_k   = drhodp_T + drhodT_p*Θ_k
c_k^2 = 1 / max(K_k, 1e-30)
```
Kapila mixture (production `kind='kapila'`, `mixture_sound_speed_sq`):
```
rho          = alpha1*rho1 + (1-alpha1)*rho2
inv_rho_c2   = alpha1/max(rho1*c1^2,eps) + (1-alpha1)/max(rho2*c2^2,eps)
c_mix^2      = 1 / max(rho * inv_rho_c2, eps)
```
Production `_phase_acoustic` wraps this and applies the **pure-branch override**
(`explicit.py:32-38`) when `alpha_pure_tol>0`:
```
pure1 = alpha >= 1 - alpha_pure_tol   → rho:=rho1, c_mix^2:=c1^2
pure2 = alpha <= alpha_pure_tol       → rho:=rho2, c_mix^2:=c2^2
Z     = max( rho * sqrt(max(c_mix^2, eps)), eps )
```
rho1,rho2 = `max(eos.density(p,T), eps)`. C++: per-cell scalar `phase_acoustic()`
returning `{rho, c_mix_sq, Z}`; caller loops over cells + ghosts.
**Ref:** `sound_speed_ref.txt` (13 α incl. pure 1e-8 / 1-1e-8 / 0.5; air+NASG-water;
columns give rho1,rho2,c1²,c2²,rho,c_mix²,Z and the raw-vs-override `c_mix_raw`).

### M3 — SLAU2 material face velocity
**`imex_ad.py:599-653`**. Pressure-free all-speed face velocity for the IMEX
split (fills `p_star`/`u_star` where `slau2_valid`, `imex_ad.py:2204-2209`):
```
c_L,c_R   = sqrt(max(c_mix_sq_ext[:-1|1:], eps))            # from M1 on ghost-extended state
c_avg     = max(0.5*(c_L+c_R), eps)
u_rms     = sqrt(0.5*(u_L^2 + u_R^2))
mach_hat  = min(1, u_rms/c_avg)
chi       = (1 - mach_hat)^2                                 # (1-Mhat)^2 coupling
rho_avg   = max(0.5*(rho_L+rho_R), eps)
v_avg     = (sqrt(rho_L)*u_L + sqrt(rho_R)*u_R)/max(sqrt(rho_L)+sqrt(rho_R), eps)  # Roe-avg velocity
u_face    = v_avg - chi*(p_R - p_L)/max(rho_avg*c_avg, eps)
p_face    = 0.5*(p_L + p_R)
valid     = finite(u_face)&finite(p_face)&(rho_L>eps)&(rho_R>eps)
```

characteristic variants — for `tmlpu` on the pure-interface 02A/07B state the
`_mixture_primitive_recon_enabled`/`_characteristic_recon_allowed` gates decide;
default falls to per-variable `reconstruct_lr_faces` with rho from EOS).
Reflective wall override: `p_face[0]=p_ext[1], u_face[0]=0` (and mirror at right).
**Ref:** `slau2_faces_ref.txt` (8-cell air|water jump + Gaussian bump, tmlpu,

### M4 — adaptive_bvd α transport
**`explicit.py:410-456`**. Topology-selected (NOT case-id): pick CICSAM
compression on genuine pure-material interfaces, MUSCL-Hancock TVD elsewhere.
Selection (`explicit.py:428-455`), `pure_tol = max(eps^0.25, alpha_pure_tol)`
(`eps^0.25 ≈ 1.2207e-4`), `pure_band = pure_tol*(1+1e-9) + 1e-15`:
```
has_low_pure  = min(interior) <= pure_band
has_high_pure = max(interior) >= 1 - pure_band
has_sharp_pure_jump = any adjacent (a_L<=pure_band & a_R>=1-pure_band) or mirror
has_narrow_mixed_layer = has_low_pure & has_high_pure & (mixed_count <= max(low+high,1))
if has_low_pure & has_high_pure & (has_sharp_pure_jump | has_narrow_mixed_layer):
    → _cicsam_alpha_face(alpha_ext,u_face,dt,dx)
else:
    → _muscl_hancock_alpha_face(alpha_ext,u_face,dt,dx,tvd_kind)
```
- CICSAM (`explicit.py:63-114`): upwind base face; per interior face NVD
  `phi_c=(up-far)/(down-far)`; if `0<=phi_c<=1`: `phi_f=min(1, phi_c/Courant)`,
  `face = far + phi_f*(down-far)`; Courant `clip(|u|dt/dx, 1e-12, 1)`; clip [0,1].
  Periodic-wrap duplicate-face handling `explicit.py:100-113`.
- MUSCL-Hancock (`explicit.py:273-319`): `slope=_tvd_slope_1d(up-far,down-up,kind)`,
  `val = up + 0.5*(1-Courant)*slope`, clamp to local `[min,max](far,up,down)`.
  `_tvd_slope_1d` (`explicit.py:246-270`): minmod/superbee/mc/umist/vanLeer,
  returns 0 if `d_up*d_down<=0`.
**Ref:** `alpha_bvd_ref.txt` (pure-jump → CICSAM branch; smooth sinusoid →
MUSCL-Hancock branch; tvd_kind='umist').

### M5 — tmlpu primitive reconstruction
**`reconstruction.py:70-232`**. 1D bounded T-MLP-u = TVD limiter clipped by a
local 3-cell maximum-principle bound. `_limited_value` (`reconstruction.py:92-129`):
```
r   = (phi_R - phi_L) / (phi_L - phi_LL)          # guard: |num|,|den|<=1e-300 → return phi_L
psi = _tvd_limiter(r, kind)                        # clamped to [0,2]
delta = 0.5*(phi_R - phi_L)
if courant given: delta *= (1 - clip(|courant|,0,1))   # MUSCL-Hancock time-centering
lo,hi = min/max(phi_LL,phi_L,phi_R)
psi_bound = (hi-phi_L)/max(delta,eps)  if delta>0   else (lo-phi_L)/min(delta,-eps) if delta<0 else 0
psi   = max(0, min(2, psi, psi_bound))             # LMP bound
return clip(phi_L + psi*delta, lo, hi)
```
`_tvd_limiter` (`reconstruction.py:70-89`): minmod `min(1,r)`, superbee
`max(min(2r,1),min(r,2),0)`, mc `max(0,min(2r,0.5(1+r),2))`, vanalbada
`(r²+r)/(r²+1)`, umist, default vanLeer `2r/(1+r)`; all `max(0,min(2,psi))`;
returns 0 for `r<=0` or non-finite. `reconstruct_upwind_faces`
(`reconstruction.py:160-197`) picks upwind cell as L via `u_face>=0`, stencil
`(f-1,f,f+1)` or mirror; `tmlpu` alias table `reconstruction.py:30-45`; scheme
`tmlpu` uses `FIVE_EQ_IMEX_TMLPU_TVD` (default `vanleer`). Floors: T1/T2 floor
1.0, p floor 1e-12, u none.
**Ref:** exercised inside `slau2_faces_ref.txt` and `step_*` refs.

### M7 — Implicit acoustic solve  ★ CRITICAL DESIGN NOTE ★
**`imex_ad.py:2736-3681`** (`_solve_acoustic_ad`).
Frozen coefficients at `W^n` (`imex_ad.py:2743-2747`):
```
rho_star = max(q1_new+q2_new, eps)
(rho_anchor, c_mix_sq, Z) = phase_acoustic(W_n)      # M1, with pure override
beta     = max(rho_anchor * c_mix_sq, eps)           # = rho c^2  (Helmholtz stiffness)
```
Face closure = **linear Wood-Z acoustic Riemann** (`_acoustic_faces_np:497-505`,
inline `face_local:2906-2910`):
```
p_f = (Z_r·p_l + Z_l·p_r + Z_l·Z_r·(u_l - u_r)) / (Z_l+Z_r)
u_f = (p_l - p_r + Z_l·u_l + Z_r·u_r) / (Z_l+Z_r)
```
Per-cell θ-method (`imex_ad.py:2855-2899`): `theta_cell = 0.5` (Crank-Nicolson)
on WAVE cells (`p_rel_face > 1e-8`), `1.0` (Backward-Euler) on flat cells;
`FIVE_EQ_IMEX_ACOUSTIC_SCHEME=theta` default. `interface_be` option forces BE in
a stencil-derived 2+1 band across pure|pure material faces (`2870-2899`).
Discrete residual per cell (scalar branch `local_res:3629-3666` — the exact
system; the n≥32 branch is the vectorised twin):
```
div_p = θ_i·(p_fr - p_fl)/dx + (1-θ_i)·div_p_old[i]
div_u = θ_i·(u_fr - u_fl)/dx + (1-θ_i)·div_u_old[i]
dp_dx = upwind(p) by sign(u0[i])                       # (p_c-p_l)/dx or (p_r-p_c)/dx
r_u   = rho_star[i]·u_c - m_adv[i] + dt·div_p          # momentum
r_p   = p_c - p0[i] + dt·(u0[i]·dp_dx + beta[i]·div_u) # pressure: Dp/Dt + rho c² div u = 0
```
`div_*_old` = old-time faces from M5/WENO5 reconstruction of `W^n`
(`_acoustic_faces_muscl_np` for n≥32, `_acoustic_faces_np` for n<32, `2778-2788`).

**HAND-DERIVED ANALYTIC JACOBIAN (replaces torch autodiff).** The Python
assembles J by `torch.func.vmap(jacrev(...))` (the speed bottleneck) with a
**straight-through rule**: the WENO5 face VALUE is nonlinear, but its Jacobian is
frozen to the **linear-optimal 5th-order stencil** (weights 1/10, 6/10, 3/10 —
see the note at `imex_ad.py:1365-1368` and `weno5_left_t:3146-3159`). Because:
1. `face_local` is **linear** in (u,p) with frozen (Z_l, Z_r);
2. `dp_dx` is a linear frozen-sign upwind difference;
3. the WENO5 straight-through derivative IS the linear-optimal WENO5 stencil;
the residual `R(y)` is an **affine function** `R(y) = J·y − b` of `y=(u,p)`.
**⇒ the straight-through torch Jacobian IS the analytic Jacobian of the frozen
linear operator, and ONE Newton step from anchor `y0=(u0,p0)` is exact:**
`y = y0 − J⁻¹·R(y0)` (`_linear_step:3555-3564`, `spsolve`). In C++ this becomes a
directly-assembled banded matrix — no autodiff.

**Banded stencil / bandwidth.** The Jacobian couples, per cell `i`, the columns
(`build_sparse_jacobian_vectorized` column map `imex_ad.py:3542-3552`):
`{i-3,i-2,i-1,i,i+1,i+2,i+3}` in BOTH the u-block and p-block ⇒ for the
`2n×2n` system ordered `[u_0..u_{n-1}, p_0..p_{n-1}]` each of the four `n×n`
sub-blocks (`∂r_u/∂u, ∂r_u/∂p, ∂r_p/∂u, ∂r_p/∂p`) is **7-point (half-bandwidth
3)** when acoustic recon = `weno5`. The i±2, i±3 couplings come ONLY from the
WENO5 5-point face stencil on material-clean faces; on same-pure/flat faces the
Riemann face uses the 3-point (i±1) stencil (half-bandwidth 1, tridiagonal).
The scalar n<32 branch (`3610-3681`) is purely tridiagonal (i±1). C++ Phase B:
assemble the 7-band `2n×2n` operator analytically and solve with LAPACK `dgbsv`
(or a block-tridiagonal solver on the i±1 core with the i±2/i±3 WENO bands).
- `∂r_u/∂u`: `rho_star[i]` on diagonal + `dt·θ·∂(div_p from face pressures)/∂u`
  (via `p_f`'s `Z_l·Z_r·(u_l-u_r)/(Z_l+Z_r)` term) → i±1 (+ WENO i±2,3).
- `∂r_u/∂p`: `dt·θ·∂(div_p)/∂p` (via `p_f` `(Z_r p_l+Z_l p_r)/(Z_l+Z_r)`) → i±1(+WENO).
- `∂r_p/∂u`: `dt·beta[i]·θ·∂(div_u)/∂u` → i±1 (+WENO).
- `∂r_p/∂p`: `1` on diagonal + `dt·(u0·∂dp_dx/∂p + beta·θ·∂(div_u)/∂p)` → i±1(+WENO).
Diagonal Tikhonov floor: `J += 1e-12·max(|diag|,1)·I` before solve (`3559-3563`).
**Ref:** `acoustic_solve_ref.txt` (40-cell interface, `FIVE_EQ_IMEX_ACOUSTIC_RECON=weno5`;
n≥32 so the production WENO5 vectorised path runs), `weno5_face_ref.txt`.

WENO5-JS face value (`_weno5_face_left_np:1396-1418`), right face of q0:
```
c0 = qmm/3 - 7qm/6 + 11q0/6 ; c1 = -qm/6 + 5q0/6 + qp/3 ; c2 = q0/3 + 5qp/6 - qpp/6
b0 = 13/12(qmm-2qm+q0)² + 1/4(qmm-4qm+3q0)²
b1 = 13/12(qm-2q0+qp)²   + 1/4(qm-qp)²
b2 = 13/12(q0-2qp+qpp)²  + 1/4(3q0-4qp+qpp)²
scale = max(b0,b1,b2, 1e-300)                 # _WENO_TINY
a_k = d_k / (1e-6 + b_k/scale)²               # d=(1/10,6/10,3/10), _WENO_EPS_REL=1e-6
value = (a0 c0 + a1 c1 + a2 c2)/(a0+a1+a2)
```

directly (a_k → d_k), i.e. the linear 5th-order stencil `[2,-13,47,27,-3]/60` per
side. WENO3-JS twin at `1373-1393` (d=(1/3,2/3)).

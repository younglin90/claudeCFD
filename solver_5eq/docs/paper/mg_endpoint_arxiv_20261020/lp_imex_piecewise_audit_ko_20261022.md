## 1. 앞선 주장 감사

### 1.0 EOS 대수 (재검증 OK)
e = Aρ^{n−1}/(n−1) + cvT, p = Aρⁿ + Γρ cvT ⇒ ρcvT = ρe − Aρⁿ/(n−1) ⇒ p = Γq + Aρⁿ(1 − Γ/(n−1)) ⇒
**q = p/Γ + Cρⁿ, C = A[1/(n−1) − 1/Γ]** ✓. (`main.tex` d = B − A/Γ, B=A/(n−1) 와 동일.)
C>0 ⇔ Γ>n−1. C=0 ⇔ Γ=n−1.

### 1.1 "A>0, n≥2 또는 Γ≥1" 정확한 적용 범위
- 출처 구조: 물질좌표 J(X)>0 프로파일의 고정 라벨 에너지 ∫[A·ρ0ⁿ J^{1−n}/(n−1) + K(X)ρ0^Γ J^{−Γ}]dX. 각 항은 ∫J^{−s}dX, **s_cold=n−1, s_th=Γ**.
- J가 끝점에서 *1차 영점*으로 접근하면 ∫J^{−s} 발산 ⇔ **s≥1**. 즉 (n−1≥1) 또는 (Γ≥1). 이것이 조건의 정체. A>0은 cold 항 양성 필요. thermal 항만 쓰려면 K>0 유계하한 필요, A≤0이면 cold 항이 −∞로 이길 수 있음 (n−1>Γ일 때). A>0이면 안전.
- **날카로움**: 1차 영점 클래스에서 iff. 내부 2차 영점(접촉)이면 s≥1/2면 충분 → 조건은 *최악 경계 접근* 기준.
- **적용 안 되는 곳**:
  1. 조각 *체적*이 0으로 가는 붕괴: m, V 고정이면 에너지 mⁿV^{1−n} → ∞, 모든 n>1, A>0 에서 성립. 위 조건 불필요.
  2. 셀당 *균일 변형* J_i (스칼라) Lagrange stage: A>0,n>1 만으로 장벽. n≥2/Γ≥1 불필요.
  3. Eulerian ρ-프로파일 양성: ρ→0 은 장벽 아님.
- **금지 가정 재확인**: 내부 Gauss 구적은 J=0 인 경계점을 평가하지 않아 발산을 못 본다. 구적 에너지는 유한. 장벽 논거는 *정확 적분* 에너지에만 성립.

### 1.2 주장 1 (단일 P2 투영)
- n=2: r_h가 L² 직교투영이면 ∫r² = ∫r_h² + ‖r−r_h‖² ✓ (피타고라스). ∫ρ_h²=∫r² 이면서 P2 모멘트 동일 ⇒ ρ_h=r_h ⇒ r∈P2. C≠0 이면 동일 p·동일 에너지 불가 ✓. 범위 = "P2 프로파일 + P2 약모멘트 유지 + n=2".
- **강화(감사 결과)**: n≠2 이면 1차항 n∫r_h^{n−1}(r−r_h) 가 일반적으로 0 아님 (r_h^{n−1}∈P2 는 n=2 에서만 일반적으로 성립. n=3 이면 r_h²∈P4⊄P2, 비정수 n 도 마찬가지). 따라서 불일치는 O(‖r−r_h‖) (n=2의 제곱보다 큼), 부호 부정. 2차항은 (n(n−1)/2)∫r_h^{n−2}(r−r_h)² >0.
- 보편 불가능 아님: Z를 독립 상태변수로 두면 해소 (§3).

### 1.3 주장 2 (균일 평형 병합)
- 두 양밀도 상태가 (V,m,Z) 보존: Z>V(m/V)ⁿ 이면 양의 2점 분포 존재 ✓ (상한 없음). 공간배치·trace·미래 응답 보존 증명 없음 ✓ (동의).
- **"미래 모든 P1 변형률 에너지 정확 유지는 정보축소 병합으로 불가"**: 에너지 E(a,b)=∫w(X)(a+bX)^{−s}dX 가 열린 (a,b) 집합에서 동일 ⇒ b에 대해 해석적 ⇒ 모든 모멘트 ∫wX^k 일치 ⇒ 콤팩트 지지 측도 w 동일 (Stieltjes 유일성). 즉 무손실 병합 = 항등. ✓ 동의 (조각의 w=ρ0ⁿ 또는 K·ρ0^Γ 두 지수 각각).
- **새 문제 (감사)**: PE 정확성은 병합이 셀·물질별 (ℓ, m, Z)를 보존하길 *요구*. Z 변경 δZ 는 I 고정 시 p 를 바꿈 (열에너지로 돌려도 순변화 −CδZ ≠ 0, C≠0). 또 Z 보존 + **최대밀도 비증가** + 입력 연속성은 동시 구성이 불분명. 내 예(n=2): 밀도 {1/2,3/2} 각 1/2 → mean=1, χ=Z/(ℓρ̄ⁿ)−1=1/4. 대칭 2값 정준족(가중 1/(2+t), (1+t)/(2+t), 값 1+t, 1/(1+t); n=2에서 χ=t²/(1+t), 모든 n>1에서 χ(t) 증가 증명 가능)로 병합하면 t≈0.640, 최대밀도 1.640 > 1.5. ⇒ 점별 T>0 을 병합이 깰 수 있음. → 점별 온도 대신 **모멘트 수준 온도**(§2)로 허용상태 정의해야 함.
- 고정 차원 닫힘 불가(no-go): P1 조각은 χ ≤ 2ⁿ/(n+1) − 1 (n=2: 1/3) 만 실현. 급경사 합집합(예: 밀도 1, 5 같은 길이, n=2: χ=13/9−1=4/9>1/3)은 P1 하나로 병합 불가 ⇒ 병합 가능성 판정은 불연속.

### 1.4 주장 3 (압축 종점)
- 고정 조각·고정 엔트로피 프로파일의 단일 해밀턴 계 H=½π·M⁻¹π+E(x): AVF 해는 에너지 정확 보존. **존재 증명(소 dt 아님)**: x⁺−x⁻ = τM⁻¹π⁻ − (τ²/2)M⁻¹∇̄E(x⁻,x⁺)=0 꼴, τ=0 에서 항등 → 차수 1. 에너지 항등식으로 해는 E(x⁺)≤H₀, 운동량 한계로 |x⁺−x⁻|≤Cτ → 콤팩트 부분집합(장벽이 경계 차단, 영역 볼록). τ를 θτ로 호모토피 ⇒ 차수 1 ⇒ **모든 τ>0 에서 존재**. 유일성 아님. ✓ 동의, 범위 = 해밀턴 단일계.
- **중요한 불일치 (감사)**: 고정 엔트로피 조각을 균일 변형 λ로 압축하면 밀도 ρ인 조각의 압력 p'=Aρⁿλ^{−n} + (p0−Aρⁿ)λ^{−(1+Γ)}. **ρ가 다르면 p'도 다르다 ⇔ n≠1+Γ ⇔ C≠0.** 셀 isobaric 닫힘(단일 p)과 양립 불가. 5방정식 Allaire 닫힘은 조각 엔트로피 보존이 아니라 "총에너지 + 공통 p" 로 에너지 분배. 따라서 주장 3의 결과는 *isobaric LP-IMEX 압축 stage의 정리가 아님*(동의) — 이유는 목록 밖 이 에너지 분배 불일치.
- 본 알고리즘은 이 점을 피함: 조각 에너지를 개별 보존하지 않고 셀 p로 분배, Z_r→J^{1−n}Z_r 로만 진화.

### 1.5 주장 4 (상대엔트로피 반례) — 직접 재검증 OK
- U: 접촉 (ρ_a|ρ_b), 같은 p, 균일 속도 ε. V: 동일하나 u=0. U(t,x)=U0(x−εt), V 정지.
- H(0)=∫η(U|V)dx = ε²∫ρ/(2θ)+O(ε³)=O(ε²) (차이는 속도뿐).
- 시각 t: 폭 εt 띠에서 U, V는 서로 다른 밀도·같은 p,u(근사). η(U|V)≥c0(ρ_a,ρ_b,p)>0 (엄격 볼록 + U≠V) ⇒ **H(t) ≥ c0 ε t**.
- d=√H: d(t)/d(0) ≥ √(c0 t/(Cε)) → ∞ (ε→0). 한 스텝 τ 에서도 ε≪τ 이면 (1+Cτ)d(0) < d(τ). 반례 유효.
- 의미: **정렬 없는 √(상대엔트로피)** 가 (1+Cτ)-립시츠일 수 없다. 정렬 거리 D=√H_aligned+|σ| (σ=계면 위치차)는 이 예를 통과(ε·(1+t)). 일반 정리는 **미증명**.
- **Leger–Vasseur 적용 불가 확인 (원문 읽음)**: Thm 1.1은 *extremal* 충격(1-,n-쇼크)만. 원문 인용: "our result does not provide the stability of contact discontinuities for this system. The problem is that the contact discontinuities correspond to 2-waves (with a middle eigenvalue)." Thm 1.2는 가장 작은/큰 고유값 족이 GNL/LD일 때만. MG 5방정식의 계면은 **중간족(u-파)**. 결과 형태도 L²-up-to-translation: ∫|U(T,x+x(T))−U_R|² ≤ Cε(1+T), |x(t)−σt| ≤ C√(εt)(1+t) — (1+Cτ) 립시츠 아님. → 이 경로로는 직접 못 쓴다. 필요: 중간족(선형 퇴화) 확장 = 미증명.

### 1.6 주장 5 (임계 병합)
- 불연속 ✓: 병합 오차가 θ 경계에서 O(θ) 점프, 두 상태 거리는 →0 ⇒ 두 계산 상태 간 립시츠 불가.
- **정정 (중요)**: e_{n+1}를 정확해에 대해 재귀할 때는 병합 사상의 립시츠가 필요 없다.
  e_{n+1} ≤ d(M S U_n, S U_n) + d(S U_n, S U(t_n)) + d(S U(t_n), U(t_{n+1})) ≤ b_n + (1+Cτ)e_n + 국소오차.
  필요한 것: (i) 병합 안 된 1스텝 S 의 **약-강 안정성**(한 쪽이 매끄러운 정확해) (ii) b_n 이 *그 안정성 거리*에서 작음. 따라서 임계 불연속 자체는 *재귀*를 막지 않음. 막는 것: 두 계산 상태 비교, 음해 연속 의존, 합성 사상을 한 덩어리로 쓰는 안정성.
- b_n 예산: Σb_n ≤ C(h²+τ²), 스텝 수 T/τ ⇒ b_n ≲ τ(h²+τ²). 매 스텝 매 셀 병합이 프로파일을 O(h²) 점별로 바꾸면 전역 O(N·h²)=O(h) ⇒ **부족**. 병합은 FV 슬로프 재계산 같은 *국소 투영*으로, 플럭스 오차 O(h²)로 표현돼야 함 (표준 2차 FV 일관성과 동치) — 증명 필요.
- 본 설계는 임계 병합을 **쓰지 않음**: 덧셈 합집합만 (§3).

## 2. 상태 공간과 허용 집합 (가장 좁은 비자명 범위)

1D 주기, 격자 N, 간격 h, 2상(일반화 가능). 상 k: (A_k>0, n_k>1, Γ_k>0, cv_k>0). C_k=A_k[1/(n_k−1)−1/Γ_k], 부호 임의.

**조각(region)**: r=(k_r, 구간 I_r⊂셀, ℓ_r=|I_r|, m_r, Z_r). 셀마다 위치 순서 목록, 인접 동종은 한 조각으로 합침. 셀 총량: V_k=Σℓ_r, m_k, Z_k, 운동량 Mo, 총에너지 𝔈. (면적 α 사용 안 함: α_k=V_k/h 는 파생량.)

**복호**: u=Mo/m, I=𝔈−Mo²/(2m), S=Σ_kV_k/Γ_k (≥h/maxΓ, α_min 무관), **p=(I−Σ_kC_kZ_k)/S**. 조각 열에너지 θ_r=(pℓ_r−A_kZ_r)/Γ_k.

**허용 집합 𝒜**: ℓ_r≥0; (ℓ_r=0⇒m_r=Z_r=0); Z_r ≥ Φ_k(ℓ_r,m_r)=m_rⁿℓ_r^{1−n} (젠센); m>0; **θ_r>0 (ℓ_r>0)**.
- 의미: θ_r>0 ⇔ p > A_k z̄_r, z̄_r=Z_r/ℓ_r (조각 *평균* ρⁿ). 점별 T>0 보다 약함 — 병합/절단이 점별 최대밀도를 보장하지 않으므로 이것이 올바른 객체 (§1.3).
- 젠센 집합은 합 아래 닫힘: Φ는 볼록·1차동차 ⇒ 부가법 하위: Φ(ℓ1+ℓ2,m1+m2) ≤ Φ1+Φ2 ≤ Z1+Z2. 비례절단 닫힘. 변형 (ℓ,m,Z)→(Jℓ,m,J^{1−n}Z) 닫힘 (Φ(Jℓ,m)=J^{1−n}Φ).

## 3. 알고리즘 LP-IMEX-MP (L0 닫힘)

한 스텝 τ. 입력 U^n∈𝒜.

**Stage L (Lagrange, 음, 중점)**. 미지수 U^L=(Mo^L,𝔈^L) (셀별).
- 면 값: u\*_f=½({u^n}_f+{u^L}_f), p\*_f=½({p^n}_f+{p^L}_f), {·}_f=이웃 셀 산술평균. 변위 δ_f=τu\*_f.
- J_i=1+(δ_{i+1/2}−δ_{i−1/2})/h. 요구 J_i>0.
- 조각: ℓ_r^L=J_iℓ_r, m_r^L=m_r, **Z_r^L=J_i^{1−n}Z_r**.
- Mo^L_i=Mo_i−τ(p\*_{i+1/2}−p\*_{i−1/2}); 𝔈^L_i=𝔈_i−τ(p\*u\*_{i+1/2}−p\*u\*_{i−1/2}).
- u^L=Mo^L/m, p^L=복호(U^L) (V_k^L, Z_k^L 사용).
- 분기: τ=0 연속 분기 (IFT, 해 Jacobian=I).

**Stage R (Eulerian 수송, 명시)**. Lagrange 셀 i = [x_{i−1/2}+δ_{i−1/2}, x_{i+1/2}+δ_{i+1/2}], 조각은 J_i로 아핀 사상된 위치.
- 조각 내용 배분 Ê_r = p^Lℓ_r^L/Γ_k + C_kZ_r^L + ½ m_r(u^L)² (Σ_rÊ_r=𝔈^L 항등 ✓: I^L=p^LS^L+ΣCZ^L).
- 면 f 의 flux: δ_f>0 이면 왼쪽 L-셀의 오른쪽 끝 띠 [x_f,x_f+δ_f] 의 조각 내용 (비례절단), δ_f<0 이면 오른쪽 L-셀 왼쪽 끝 띠. 대상 양: m_r, Z_r^L, ℓ_r^L, m_ru^L, Ê_r. 상류 = u\* 부호.
- 새 셀: 유입·잔류 조각 합. 같은 물질 인접 조각은 **덧셈 합집합** (구간 합, 모멘트 합). 임계값 없음.
- 요구 CFL: J_i>0 (모든 스텝), |δ_f| ≤ h (flux가 한 셀만 참조 — 보존·양성엔 불필요, Eulerian flux 해석에만 필요).
- 새 셀 u=Mo/m, p=복호.

Allaire(a_t+ua_x=0, `main.tex` §2 확인: ∂_t a+∂_x(au)=a∂_xu ⇔ a_t+ua_x=0)에서 계면은 Lagrange 이동. 조각 구간 경계가 계면 위치이므로 계면은 *명시적 마커*.

**경계조건**: 주기만 증명. 벽/유입은 미정의(미증명).
**상 소멸·출현**: 조각의 *전역 구간*은 Jℓ>0 으로 영원히 양. 셀 점유 ℓ_{k,cell}만 0↔양수. 물질 전체 소멸(J→0)은 범위 밖.
**가정 R (해상도)**: 셀당 계면 수가 유한(조각 수 ≤ 1+계면 수). 계면 수 *비증가*(Lagrange 연속 사상, 절단은 계면 생성 안 함) ⇒ 조각 수 폭주 없음.

**수정 레벨 L1 (선택)**: flux를 절단 비례배분 대신 같은 상 이웃 조각의 *강도량* (m_r/ℓ_r, Z_r/ℓ_r) 의 제한 선형 재구성 적분으로 계산, p·u 는 상수 재구성. 보존·PE는 L0과 동일 논증으로 유지(증명 한 줄: 모든 flux가 같은 재구성 필드의 적분이고 p,u 재구성이 상수를 재현). 양성은 젠센 집합이 볼록이므로 셀 평균 쪽 스케일링 한정자 필요. 차수는 미증명.

## 4. 정리와 증명

### T1 (닫힘)
Stage R 은 𝒜 의 *젠센·구간* 부분을 보존: 비례절단과 덧셈 합집합은 §2 의 닫힘 때문. Stage L 은 J>0 이면 젠센 보존. □

### T2 (정확 보존)
Stage L: Mo, 𝔈 은 면 flux 망원합, m_k 불변 → 합 보존. Stage R: Lagrange 셀 내용의 분할 → 각 양 합 불변. 따라서 ΣMo, Σ𝔈, Σm_k 보존 (기계 정밀도 아닌 *정확*, 엄밀해 가정). Σℓ_r 은 보존되지 않음(압축). □

### T3 (균일 p0,u0 평형 보존, 임의 C)
**가정**: U^n 모든 셀 (u0,p0), U^n∈𝒜.
1. Stage L: u\*=u0, p\*=p0 ⇒ J=1, Mo^L=Mo, 𝔈^L=𝔈, 조각 불변이 방정식의 해이고 τ=0 연속 분기와 일치 (분기 유일). ⇒ u^L=u0,p^L=p0, δ_f=τu0 균일.
2. Stage R: 균일 평행이동. 새 셀 총량: m_k, Z_k, V_k: 이동된 조각 합. Mo=u0m, 𝔈=Σ_rÊ_r 합 = Σ_k[p0V_k/Γ_k + C_kZ_k] + ½u0²m ⇒ I = p0S+ΣCZ, 복호 p=(I−ΣCZ)/S = p0 ✓, u=Mo/m=u0 ✓.
3. 열에너지: θ_r=(p0ℓ_r−A_kZ_r)/Γ_k 는 (ℓ,Z) 선형 ⇒ 절단·합집합 아래 양성 유지 (각 piece 가 이미 θ>0 이면 합도 >0, 비례절단도 >0). 젠센은 T1. ∎
- 필수 조건: 병합/절단이 *셀·물질별 (ℓ_r, m_r, Z_r)* 를 정확히 배분. Z 를 상태에서 빼면(파생 Z=ℓρ̄ⁿ) C≠0 에서 위 3번 대신 p≠p0 (젠센 격차 때문) — 이것이 단일 P2/단일 밀도 닫힘이 막히는 이유와 같은 구조.
- 이 정리는 `main.tex` 의 종점 평균(이산기울기)이 *필요 없다*: 시간 이산은 정확 평행이동, 공간 이산은 비례절단이므로 압력평형은 Z 상태변수와 일관 flux 로 해결. (한계: 일반 유동 시간 이산기울기 대응은 별도.)

### T4 (0↔양수 전환, α_min 무의존)
복호의 분모는 S≥h/maxΓ, m>0. flux 비례계수는 *같은 조각 안* 길이비 ∈[0,1]. 어디에도 α_k 나눗셈 없음. 셀 점유 ℓ_{k,cell} = 조각∩셀 길이, 계면이 면을 지날 때 정확히 0↔양수 (기하 교차, 문턱 없음). ∎

### T5 (Lemma K: 계면 운동학)
계면 마커 X (셀 i 내 분율 ξ). 1스텝 위치: X⁺ = X + (1−ξ)δ_L + ξδ_R (아핀 사상, 정확). 정확 흐름 변위함수 D(x)=Φ_τ(x)−x 의 두 면 값을 δ로 근사.
**가설 H_u**: |δ_f − D(x_f)| ≤ C_uτ(h²+τ²) (계면 근방 면들).
그러면 |X⁺−Φ_τ(X(t))| ≤ ... 재귀:
|X_{n+1}−X(t_{n+1})| ≤ (1+L_uτ)|X_n−X(t_n)| + Cτ(h²+τ²).
증명: X_{n+1}−X(t_{n+1}) = [X_n−X(t_n)] + [I_hδ(X_n) − D(X(t_n))]. I_hδ=D의 선형보간+면 오차: |I_hδ(X_n) − D(X_n)| ≤ ½h²‖D''‖+C_uτ(h²+τ²), ‖D''‖=O(τ). |D(X_n)−D(X(t_n))| ≤ Lip(D)|X_n−X(t_n)|, Lip(D)≤L_uτ. 합. ∎
- 위치 오차는 **병합과 무관** (병합 없음, 덧셈 합집합은 경계 불이동).
- **이것은 유한시간 2차 증명이 아님**: H_u(음향 stage 가 면 변위를 2차로 맞춤) 가 가설. 닫힘 오차가 계면 근방 u 를 O(h) 로 오염시키면 H_u 거짓.
- 국소 정리 H_u 점검: 시간 중점 면 속도 u\*는 시간 중심이나, 위치 중점 평가가 아닌 고정 아핀 이동이므로 2차 여부는 Lagrange 면속도 일관성에 의존 — 미증명.

### T6 (선형 수송 구간 안정성 상수 = 1, α_min 무관)
고정 기하(같은 L-셀 분할, 같은 δ_f)에서 Stage R 은 조각 내용에 대한 *양의 선형 사상*, 각 내용이 가중치 합 1로 분할 ⇒ ℓ¹(조각 내용 합) 비확대:‖T w‖₁ ≤ ‖w‖₁. 물리공간 L1 에서도: 조각 프로파일 f(x) 에 대해 평행이동(등척) 후 합집합 평균(조건기대) → L1 수축. 상수 1.
- 한계: 두 상태의 *계면 위치가 다르면* 분할이 달라 L1 립시츠 아님 (|이동|×점프). 이것이 §1.5 반례의 이산판. 필요: 정렬 거리 (미증명).

## 6. 요구한 증명 구조가 막힌 지점

e_{n+1} ≤ (1+Cτ)e_n + Cτh² + Cτ³ + b_n, Σb_n ≤ C(h²+τ²).
- (a) **(1+Cτ) 와 α_min 독립 C**: 선형 수송 구간 상수=1 (T6). 음향–EOS 결합 포함 일반 유동은 무증명. 후보 거리 D=√H_aligned + |σ| 는 §1.5 반례를 통과하지만 정의·안정성 증명 없음. LV 는 중간족 불포함. 혼합 Wood 음속 (Σα_k/(ρ_kc_k²))⁻¹ 가 순수상 값 사이라서 α_min 무의존이 *그럴듯*하나 증명 아님.
- (b) **b_n 예산 ≲ τ(h²+τ²)**: L0 닫힘 오차 = 조각 내부 배열 무시. 매끄러운 필드에서 절단 띠의 Z·m 배분 오차 = O(h|∂ρ|)×띠 → 국소 1차. 균일 분석(발견적): 평활화로 저장된 *하위격자 분산* Z−Φ 가 O(1) 시간에 O(h) 누적 → 압력 O(h) (PE는 정확, 비평형은 1차). 2차는 L1 재구성이 필요, 평균 안정성 증명 없음.
- (c) 병합 임계 불연속은 본 설계에서 없음. 단 L1 한정자(스케일링)는 연속이나 비매끄러움(Lipschitz); 오차 예산 증명 없음.
- (d) 음향 stage 존재: 소 dt (IFT, 수축 τL<1, L~(K_p+K_u)/h = 음향 CFL형). 큰 dt 존재는 해밀턴 구조(§1.4)에서만 증명, 셀중심 FV 중점으로는 미증명 → 이것이 "IMEX" 의 핵심 이득을 증명 못하는 점.
- (e) 양성: 평형 구간 증명 (T3). 일반 유동 소 τ 마진 논증: 강도량 마진 μ=min_r(p−A_kz̄_r)/p 는 α_min 무관, p^L−p=O(τ), J−1=O(τ) 이므로 τ≲μ·p_min/C' 필요(C'는 α_min 무의존이나 *수축 상수* 포함) — 단 I7 혼합 문제로 *셀 간 p 차*가 있으면 Stage R 에서 깨질 수 있어 완전하지 않음 → "소 τ + 마진" 조건부.

## 11. 후속 (2026-10-22): §10-1 평형 구간 L1 안정성 — 계산 없이 해석 유도

범위: 균일 (u0>0, p0) 평형 구간, 이 구간에서 Stage L 항등 → 1스텝 = 평행이동 δ=νh (0<ν≤1) + L0 조각 평균. 물질별 질량밀도 프로파일 g_k(x) (Z 장도 동일 구조), 거리 = 물리공간 L1 (비정렬; 계면 위치 오차는 e·점프로 자동 포함).

**T7a (균일 접촉, 정확 등척).** 각 물질 조각의 강도량 (m/ℓ, Z/ℓ) 이 물질마다 상수이면 조각 평균은 항등. 1스텝 = 정확한 평행이동. ⇒ ‖TU−TV‖₁ = ‖U−V‖₁, 계면 위치 임의, 점유 임의. 상수 1. (§1.5 반례 계열 U,V 에도 성립: 거리가 ε t 로 자라지만 이는 *서로 다른 속도*의 해이고 여기선 같은 u0.)

**T7b (한 계면, 정확 항등식).** 물질1 | 물질2, 계면이 한 셀 c 안에 머물고 (ξ_U h, ξ_V h = ξ_Uh + e, e>0 작음), 다른 모든 조각은 U,V 동일. 상류 셀 c−1 강도량 a, 셀 c 의 물질1 강도량 b, s=ξh, ℓ'=δ+s_V. 새 셀 c 의 물질1 조각 강도량 g' = (δa + s b)/(δ+s) = b + δ(a−b)/(δ+s).
- 질량차: δa+s_Vb − (δa+s_Ub) = e b (불변).
- L1: |g'_U−g'_V|·ℓ'_U + g'_V e, g'_V−g'_U = (b−a)δe/(ℓ'_Uℓ'_V) ⇒
  **‖TU−TV‖₁ = ‖U−V‖₁ + 2eδ(a−b)₊/ℓ'_V**, ‖U−V‖₁ 의 계면 셀 기여 = e(b+d) (물질1 쪽 e·b, 물질2 쪽 e·d; d=셀 c 물질2 강도량). 물질2 쪽은 스텝 후에도 e·d 로 불변이라 증가는 물질1 항에서만 발생.
- 즉 a≤b (상류 강도량이 계면 쪽보다 작거나 같음) 이면 성장 0. a>b 이면 증가량 ≤ 2e(a−b)₊·(δ/ℓ'_V), δ/ℓ'_V ≤ 1: **점유 s 에 무관**(분모 ℓ'_V ≥ δ).
- 매끄러운 필드: (a−b) = O(h|ρ'|) ⇒ 스텝당 인자 1 + C·ν·h|ρ'|/ρ = 1 + O(τ) ✓ ((1+Cτ) 형). 물질 내부에 O(1) 점프(충격·희박파가 계면 옆)이면 스텝당 O(1) 인자 → 이 증명 불가.
- 한계: 인접 계면 간 간섭, 계면이 면을 건너는 스텝(유사 계산 필요), Z·Φ 조건 포함 수치 상수 미계산, u 가변 아님.

**의미.** 정렬 거리 D 를 쓰지 않고도 평형 구간에서는 L1 이 균일 접촉 정확 등척, 매끄러운 강도량이면 (1+Cτ) 성장. 정렬 거리 필요성은 *일반 유동*(속도차가 계면 위치를 벌리는 §1.5 반례 구조)에서 남음.
**아직 안 됨:** 가변 속도, 음향 결합, 일반 비선형 (§6 a–e 그대로).

## 12. 후속 2: 계면이 셀 면을 넘는 스텝 (u0>0, 한 계면, 평형 구간)

기호: 상류 셀 c−1 물질1 강도량 a; 셀 c: 물질1 b (길이 s), 물질2 d (길이 h−s); 하류 셀 c+1 물질2 f. δ=νh, e=두 상태 계면 위치차. 거리 = 물질별 L1 합.

**영역 N (s+δ≤h, 통과 안 함)**: §11 항등식, 증가 = 2eδ(a−b)₊/(δ+s_V).
**영역 C (s+δ>h, 통과)**: 새 셀 c = 전부 물질1 (내용 δa+(h−δ)b, s 무관 → 차이 0). 새 셀 c+1: 물질1 조각 길이 w=s+δ−h 강도량 b (순수), 물질2 조각 길이 h−w, 내용 d(h−s)+f(h−δ).
q=h−δ, r=h−s 로 g₂=(dr+fq)/(r+q). U,V 비교(길이 e 차): 
 증가 = e[g₂_U − d + |d−f|q/(r+q)] = **2e·q(f−d)₊/(h−w)**, q/(h−w) ≤ 1 (w≤δ).
**경계 통과 스텝 (U는 N, V는 C)**: 사상 T 는 s 에 연속 (s+δ=h 에서 두 공식 일치: 새 c 전부 물질1, c+1 내용 dδ+f(h−δ)). 임계 상태 U\*에서 삼각부등식, 간격 e1+e2=e (단조 이동이라 L1 간격 가산):
 ‖TU−TV‖₁ ≤ ‖U−V‖₁ + 2e·max{(a−b)₊, (f−d)₊}.

**정리 T8 (평형 구간, 한 계면, u0>0; u0<0 은 거울)**: 모든 영역에서
 ‖TU−TV‖₁ ≤ ‖U−V‖₁ + 2e·max{(a−b)₊, (f−d)₊}·θ, θ∈[0,1] (θ=δ/(δ+s) 또는 q/(h−w)).
점유율(s, h−s, w)에 대한 나눗셈은 모두 비율 ≤1 → **α_min 무의존**. Z 장도 같은 구조 (강도량 z̄=Z/ℓ 로 대체, 장별로 합).

**정직한 상수 평가 (발견적, 합산)**: 계면이 한 셀을 통과하는 동안 s=ξh, ξ_k=ξ₀+kν. 영역 N 의 θ_k=ν/(ν+ξ_k) 합 ≈ Σ1/(1+k) ≈ ln(1/ν)+γ. 따라서 매끄러운 필드(a−b, f−d = O(h|ρ'|))에서 단위시간 성장 지수 ≈ 2u(|ρ'|/ρ)(ln(1/ν)+O(1)). **CFL ν 고정이면 (1+Cτ) 형 성립하나 C 가 ν→0 에서 로그 발산.** 점유율 무의존은 유지.
→ 이는 1차 상류 평균의 수치확산이 계면 위치 오차를 강도량 차이로 증폭하는 것과 같은 구조. L1 재구성(L1 레벨)으로 (a−b)₊ 를 O(h²) 로 줄이면 개선 가능성 — 미증명.

**미해결 (평형 구간 내)**: 두 계면 간 간섭(셀 내 조각 3개 이상), 양 방향 속도 혼재, 물질2 쪽 상류 영향(영역 C의 f−d 항은 위에서 처리), 수치 상수 실계산 없음. 균일 접촉(T7a)은 이 모든 항이 0.

## 13. 후속 3: b_n (닫힘/재구성 일관성 오차) 전개, 평형 구간·매끄러운 단일 물질

설정: u0>0, δ=νh, 0<ν≤1, 매끄러운 ρ(x). 평행이동이 정확해. 셀평균 ρ̄_c=ρ(x_c)+h²ρ''/24+….

**13.1 L0 (평평한 조각).** 새 셀 값 = (1−ν)ρ̄_c + νρ̄_{c−1} (1차 상류). 정확 평행이동의 셀평균 대비 국소오차:
 E_loc = ν(1−ν)h²ρ''/2 + O(h³).
(전개: L0 = ρ − νhρ' + νh²ρ''/2, 정확 = ρ − νhρ' + ν²h²ρ''/2.)
상류 혼합은 볼록결합 → L1 비확대. 따라서 L1 전역오차 ≤ Σ_n Σ_c h|E_loc| = (Tu/(νh))·ν(1−ν)h²‖ρ''‖_{L1}/2 =
 **½·T·u·(1−ν)·h·‖ρ''‖_{L1}  (엄밀, 1차)**.
목표 Σb_n ≤ C(h²+τ²) 미충족 (O(h)). 즉 L0 는 평형·매끄러운 구간에서도 1차 — §6(b) 확인.

**13.2 선형 재구성 (Fromm형, 중앙 기울기).** flux = 상류 셀 재구성 선형 프로파일의 띠 평균. 이차 ρ 에서 띠 평균 오차 = ρ''h²(1−ν)(1−2ν)/12 ·(질량분율 ν 곱 전) — 유입·유출 띠에서 *동일*이라 차이에서 상쇄. 남는 항은 ρ''' 급: **E_loc = O(ν h³ ρ''')** ⇒ 시간당 O(h²) ✓ (정확해는 이차 일관). 보존·PE 증명은 L0 과 동일 (모든 flux가 같은 재구성의 적분).
- 한계(표준 사실, 여기서 증명 안 함): 제한 없는 선형 재구성은 단조가 아님 → L1 비확대 불성립(Godunov). 제한자 도입 시 극값에서 국소 1차로 퇴화, Jensen/양성 한정자 필요. 따라서 "L1 2차"는 *매끄러운 극값 없는 구간* 한정이며 전역 증명 아님.

**13.3 하위격자 분산(Z−Φ) 누적식.** L0 한 스텝 혼합이 만드는 초과:
 ΔZ_exc = (n(n−1)/2)·ρ^{n−2}·ν(1−ν)(ρ_c−ρ_{c−1})² = (n(n−1)/2)ρ^{n−2}ν(1−ν)h²ρ'² (스텝당, 국소).
Z_exc 도 질량과 같은 상류 수송으로 이동하므로 시간당 원천 (n(n−1)/2)ρ^{n−2}(1−ν)u h ρ'² ⇒ **O(1) 시간 후 Z_exc = O(h)**. 평형(p0 균일)에서는 PE 정확(T3)이라 압력 영향 없음. 비평형에서 p=(I−ΣCZ)/S 에 C·Z_exc = O(h) 오차(=1차)가 들어감. 재구성 레벨에서는 ρ 자체의 혼합 오차가 O(h²) → 원천 O(h²ρ'²/τ)가 아니라 [재구성 평활화는 슬로프 제한자 의존] 증명 안 됨.

**13.4 로그 인자는 재구성으로 안 없어진다 (정정).** §12 의 log(1/ν) 는 두 *평평하게 양자화된* 상태(계면 위치가 e 다름)를 비교할 때 조각 강도량 g' 가 길이에 의존해서 생김. 재구성을 써도 저장 상태가 평평이면 같은 항이 남는다 (g' 의 길이 의존 e·ρ'/2 · ℓ' = O(e h ρ')). 없애려면 *재구성된 함수*들 사이의 거리(재구성 인식 L1)가 필요 — 미증명.

**13.5 정리 (이번 소결).**
(i) 평형·매끄러운 단일 물질·u0>0: L0 전역 L1 오차 ≤ ½Tu(1−ν)h‖ρ''‖₁ (증명됨, 1차).
(ii) 선형 재구성: 일관성 O(h²) (증명됨, 극값 없음 가정), 안정성/양성/PE: PE·보존 증명됨, L1 안정성 미증명.
(iii) 계면 위치 오차 증폭 상수: 점유율 무의존, ν→0 로그 발산, 재구성으로 안 줄어듦.

## 14. 후속 4 (프롬프트 1): 해밀턴 AVF 음향 변형 — 큰 dt 존재, 에너지 일관 KE

**모델 (엇갈림 격자).** 면 위치 x_f, 면 속도 w_f, 면 질량 M_f=(m_i+m_{i+1})/2>0 (셀 질량 m_i 는 Lagrange 동안 불변). 셀 부피 L_i=x_{i+1/2}−x_{i−1/2}. 셀 i 의 *모델 등엔트로피* 내부에너지 E_i(L): 셀 데이터 (V_k,Z_k) 로부터 J=L/h 에서
 I(J)=S0·J·p+Σ_kC_kZ_kJ^{1−n_k}, dI=−p dL.
정리하면 p 의 선형 ODE: dp/dJ=−(1+Γ_m)p/J+Γ_mΣ_kC_k(n_k−1)Z_kJ^{−n_k−1}, Γ_m=1/S0 (h=1 단위). 해(닫힌형):
 p(J)=J^{−(1+Γ_m)}[p0+Γ_mΣ_kC_k(n_k−1)Z_k(J^{Γ_m−n_k+1}−1)/(Γ_m−n_k+1)] (분모 0이면 로그).
검산: 단상이면 Aρ0ⁿJ^{−n}+(p0−Aρ0ⁿ)J^{−1−Γ} (정확한 등엔트로피 압력과 일치; ΓC(n−1)=A(Γ−n+1) 사용).
E_i(L)=I0−∫p dL.

**가설 H_c** (상태 조건; ⚠ 혼합상 일부 범위에서 거짓 → §26-1): E_i∈C², E_i''=−p'/…>0 (실수 음속), E_i≥0, J→0⁺ 에서 E_i→∞. 단상 A>0,n>1,K>0 은 만족. 혼합상은 상태 조건이며 증명 안 함.

**AVF 단계.** H=½Σ_fM_fw_f²+Σ_iE_i(L_i).
 x⁺−x⁻=τ(w⁻+w⁺)/2, M(w⁺−w⁻)=−τ∇̄U.
셀 항이 L_i 하나의 함수라 AVF 벡터는 셀별 *할선 압력* p̃_i=−[E_i(L_i⁺)−E_i(L_i⁻)]/(L_i⁺−L_i⁻) (ΔL=0 이면 p_i)로 환원: ∇̄U_f=p̃_{i+1}−p̃_i.
에너지 항등식: Σ_fM_f(w⁺−w⁻)·(w⁺+w⁻)/2=−∇̄U·Δx=−Σ_ip̃_iΔL_i... ⇒ **H⁺=H⁻ 정확**.

**정리 H1 (모든 τ>0 에서 존재; H_c 성립 셀 한정 → §26-1).** H_c 하에 주기 링의 위 방정식은 L_i⁺>0 인 해를 갖는다.
증명. w⁺ 소거: G(x⁺;τ)=M(x⁺−x⁻−τw⁻)+(τ²/2)∇̄U(x⁻,x⁺)=0. Ω={모든 L_i>0}는 볼록(선형 부등식) → 선분이 Ω 안에 있어 ∇̄U 연속.
선험 한계: 해는 H⁺=H⁻ 를 만족. E_i≥0 이므로 운동에너지 ≤H0 ⇒ |w⁺|_M≤√(2H0) ⇒ |x⁺−x⁻|≤Cτ. 또 E_i(L_i⁺)≤H0 와 J→0 에서 E→∞ ⇒ L_i⁺≥L_min>0 (τ 무관).
호모토피 τ→θτ, θ∈[0,1]: 모든 θ 에서 해는 같은 콤팩트 K⊂Ω 내부에 있으므로 경계 영점 없음. θ=0 에서 G=M(x⁺−x⁻)는 x⁺=x⁻ 에서 차수 +1. 차수 불변 ⇒ 차수 1 ⇒ 영점 존재. ∎
- 유일성 아님. **PE 분기 선택 미해결**: 균일 w=u0, p0 이면 Δx=τu0, ΔL=0, p̃=p0, G=0 이므로 PE 상태는 *해*이나 다른 해가 공존할 수 있음(공진). 선택 규칙(연속 분기, 최소 H-증분 등)이 없으면 PE 보존 *정리*가 아님. 소 τ 에서는 IFT 로 유일.
- **열에너지 양성**: E_i(L) 이 모델 등엔트로피이므로 L⁺ 에서의 압력은 정확한 모델 압력 p(J⁺) (할선 아님). 단상 셀이면 θ=(p−Az̄J^{−n})Jℓ/Γ 가 정확히 (p0−Az̄)J^{−1−Γ}>0 로 *모든 τ 에서* 양. 혼합 셀은 q_r=p−A z̄_rJ^{−n} 의 부호가 공통 p 닫힘에서 자동이 아님 → 가설 H_T (모델 등엔트로피 구간에서 모든 조각 q_r>0).

**에너지 일관 KE 연결 (셀중심 FV ↔ 엇갈림).**
- 운동량: u_i=(w_{i−1/2}+w_{i+1/2})/2 면 Σ_im_iu_i=Σ_fM_fw_f (정확).
- 운동에너지: Σ_f½M_fw_f² = Σ_i½m_iu_i² + Σ_i½m_i((w_R−w_L)/2)² — *셀 내 압축 모드 KE* 차이.
- 보존을 정확히 하려면 셀 총에너지에 𝔈_i = E_i(L_i⁺)+½m_iu_i²+½m_i(Δw_i/2)² 로 **차이를 셀 내부에너지(열)로 계상**. Σ𝔈=H 정확.
- 역방향 사상 u→w 는 질량가중 w_f=(m_iu_i+m_{i+1}u_{i+1})/(m_i+m_{i+1}) 이 운동량 정확 (M_fw_f=(m_iu_i+m_{i+1}u_{i+1})/2).
- **발견된 문제**: 셀중심 상태에서 시작해 w 로 사상하면 KE_cell−KE_nodal=O(h²)(상대) 가 스텝마다 열로 계상된다. 스텝 수 ~1/h ⇒ 누적 O(h), 스텝당 O(h²) ≫ 2차 허용 O(τh²)=O(h³). 즉 **셀중심↔엇갈림 변환을 매 스텝 거치면 가짜 가열이 1차**. 해결: w 를 상태로 유지하는 엇갈림 LP(노드 운동량 remap 필요, 미정의) 또는 가열이 없는 변환 설계. 미증명.

**소결.** H1: 큰 dt 존재는 해밀턴 *엇갈림* 형태에서 증명됨 (§6(d) 부분 해소). 대가: 셀중심 변환 가열(1차)과 PE 분기 선택 미해결.

## 15. 후속 5 (프롬프트 2): 재구성 인식 L1 / 로그 인자 — 정정과 소결

**정정 (§12).** §12 의 합산 ≈ 2eu(ρ'/…)(ln(1/ν)+γ) 를 "성장 지수"라 한 것은 틀림. T8 의 증가 2eθ(a−b)₊ 는 *e 에 비례*하며 평형 구간에서 계면 위치차 e 는 **정확히 불변**(양쪽이 같은 δ 로 이동). 따라서 반복하면 **선형 시간 성장**:
 ‖TⁿU−TⁿV‖₁ ≤ ‖U−V‖₁ + 2e·Σ_nθ_n(a−b)₊ ≈ ‖U−V‖₁ + 2e·uT·|ρ'|·(ln(1/ν)+γ).
지수 증폭이 아니라, e 에 비례하는 *가법적* 선형 항. (1+Cτ) 승법 형태는 불필요 — e 를 별도 불변량으로 추적하면 됨.

**재구성 인식 L1.** L0 의 재구성은 평평한 함수 그 자체이므로 d_R=‖R(U)−R(V)‖₁ 은 이미 쓴 L1 과 동일 → 로그는 사라지지 않음. 로그의 원인: 고정 총질량차 e·b 의 부호 있는 차(쌍극자)가 상류 평균으로 퍼지며 L1 이 증가 (부호 상쇄 이전의 크기가 커짐). 즉 L1 노름의 성질.
**후보**: 쌍극자 퍼짐이 비용이 아닌 Kantorovich–Rubinstein(평탄) 노름 ‖μ‖_KR=sup{∫φdμ: |φ|≤1, Lip φ≤1}. 쌍극자 질량 eb, 간격 ℓ → KR ≤ eb·min(2,ℓ), 퍼져도 유계.
**막힌 지점**: 조각 평균 연산자 A 는 자기수반이라 ∫φ d(Aμ)=∫(Aφ)dμ 인데, Aφ 는 1-립시츠 아님 (인접 셀 평균 도약 ≤h). 따라서 ‖Aμ‖_KR ≤ ‖μ‖_KR + h‖μ‖₁ 꼴의 손실이 나오며 이것이 다시 h·(질량) 를 스텝마다 더함 — 비확대 아님. 비확대 증명은 **미완**. 로그 소거 여부 미확정.

## 16. 후속 6 (프롬프트 3): 2상 허용집합 불변성(I7) 대조 정리

**원문 접근 한계 (정직)**: Guo–Wang–Don–Qiao JCP 115049 는 이번 세션에서 DOI(리다이렉트 본문 없음)·ResearchGate(403) 모두 열지 못함. 이웃 논문만 검색 요약 수준: Guo–Qiao–Don–Wang 2025 (경화가스, 속도일관+bound-preserving 한정자), arXiv:2007.06014 (MG 5방정식 DG + 체적분율 최대원리 한정자). **PCP 논증 원문 수식 대조는 하지 못했다.** 아래는 `source_register.md` 기록(고정 고유밀도 Thm 1, 명시 SSPRK)과 내 유도.

**유도 1 — 고정 고유밀도 가정이 볼록성을 준다.** Z_k=ρ_k^nV_k (ρ_k 상수) 이면 g_k 조건 θ_k≥0 ⇔ (I−ΣC_jρ_j^nV_j) ≥ A_kρ_k^nS(V): (I,V) 의 **선형** 부등식 → 허용집합 볼록, 볼록결합(Lax–Friedrichs 분해) 논증 가능. 독립 Z 에서는 (I−ΣC_jZ_j)ℓ_r ≥ A_kZ_rS 가 쌍선형이라 볼록 아님(I7). 이것이 고정 밀도 가정의 구조적 이유로 보임 (원문 확인 아님).

**유도 2 — 볼록 부분집합 𝒦(p\*,q).** 상수 p\*>0, 물질별 q_k>0 (A_kq_k≤p\*) 에 대해
 𝒦 = {각 셀: Num_p−p\*S ≥ 0 (Num_p=I−ΣCZ), 각 조각: Z_r ≤ q_kℓ_r, 젠센, ℓ,m≥0}.
세 조건 모두 확장량의 반공간(또는 볼록) → 𝒦 볼록. 𝒦⊂𝒜: θ_r=ℓ_r(p−Az̄_r)/Γ ≥ ℓ_r(p\*−Aq)/Γ ≥ 0.

**정리 T9 (Stage R 의 𝒦 불변; 엄격 부등식 → §26-4).** U^L∈𝒦 이고 J_i>0 이면 Stage R 결과도 𝒦.
증명. 조각 부등식과 젠센은 비례절단·덧셈에서 보존 (§2). 압력: 새 셀 내부에너지
 I_new = Σ_frag[p_cellℓ/Γ+CZ] + [Σ½m_ru_c² − Mo²/(2m)] ≥ Σ_frag p_cellℓ/Γ + ΣCZ ≥ p\*S_new + ΣCZ_new,
(둘째 항 ≥0: 속도 분산, (m,Mo)→Mo²/2m 의 볼록성; 셋째: p_cell≥p\*). ⇒ p_new≥p\*. ∎
→ 이전 I7("이웃 혼합으로 θ<0 가능")은 *일반 𝒜* 에 대해서만 맞고, 상수 하한 p\* 와 밀도 상한 q 로 제한한 상자에서는 Stage R 이 안전.

**한계.** (a) Stage L 은 𝒦 를 보존하지 않음: 압축은 z̄ 를 J^{−n} 배, p 를 변화시킴. 정확 등엔트로피면 q_r=p−Az̄J^{−n} 단상에서 (p0−Az̄)J^{−1−Γ}>0 이라 θ>0 은 유지되나 *상자 경계* (p\*,q)는 스텝마다 팽창 → 시간 의존 상자와 Gronwall 형 팽창률이 필요, 미작성. (b) 혼합 셀의 q_r>0 보존은 H_T. (c) 𝒦 불변성은 *Stage R 만*; 완전 LP-IMEX 불변성 아님.

## 17. 후속 7 (프롬프트 1): 엇갈림 LP — 노드 속도를 상태로 유지

**상태**: 셀 데이터(조각 (ℓ,m,Z), 셀 *내부에너지* I_i — KE 없음) + 노드 속도 w_f. 노드 질량 M_f=(m_i+m_{i+1})/2 (파생). 총에너지 H=Σ_iI_i+Σ_f½M_fw_f².

**Stage L**: §14 H1 (AVF, 엇갈림). 출력 x⁺=x⁻+Δx, w^L, L_i⁺. δ_f=Δx_f. 조각: ℓ→Jℓ, Z→J^{1−n}Z, J=L_i⁺/h. 셀 내부에너지 I_i^L=E_i(L_i⁺) (정확 등엔트로피). H 정확 보존 (H1).

**Stage R (셀)**: §3 와 같되 조각 내용 배분 Ê_r 에서 **KE 항 제거**: Ê_r^{int}=p^Lℓ_r^L/Γ_k+C_kZ_r^L. 질량 flux F_f (면 f 통과 질량, δ_f 부호 상류).

**Stage R (노드, 이중 격자)**. 이중 면 i (셀 i 중심) 질량 flux F^d_i=(F_{i−1/2}+F_{i+1/2})/2. 이중 셀 f=i+1/2 질량 M_f'=M_f−F^d_{i+1}+F^d_i 는 ½(m_i'+m_{i+1}')와 *정확히 일치* (대수: −(F_{i+3/2}−F_{i−1/2})/2 양쪽 동일). 노드 운동량 flux = F^d·(상류 노드 속도). 갱신 (F^d>0 예):
 M_f'w_f' = (M_f−F^d_{i+1})w_f + F^d_i w_{f−1} ⇒ w_f' 는 이웃 노드 속도의 **볼록결합**.
CFL: 이중 셀 유출 합 ≤ M_f. 증명: 유출 합=(F_{i+3/2}−F_{i−1/2})/2 ≤ (m_{i+1}+m_i)/2=M_f, 단 |δ_f| ≤ 상류 L-셀 길이.
**운동에너지 결손(젠센 갭)**: 볼록결합의 제곱 ≤ 제곱의 결합 ⇒
 Q_f = ½(M_f−F_out)F_in/M_f' · (w_f−w_{f−1})² ≥ 0 (정확식, F_in≥0 일 때; 반대 방향도 대칭).
Σ½M'w'² + ΣQ_f = Σ½Mw² 정확 (유입·유출 망원). Q_f 를 두 노드 (f−1,f) 를 끼는 **셀 i 의 내부에너지에 가산** (국소).

**정리 S1.** (i) 총에너지 H 정확 보존 (Stage L: H1, Stage R: Q 계상). (ii) 운동량 ΣM_fw_f 와 질량 정확 보존. (iii) Q≥0 → 내부에너지 증가 → 압력·θ 증가 (양성에 유리). (iv) 균일 w=u0, p0 이면 Q=0 이고 §T3 논증이 KE 항 없이 그대로 적용: PE 보존 (H1 분기 선택 문제는 §14 대로 별도).
**가짜 가열 판정**: §14 의 "셀중심↔엇갈림 변환 가열"은 **사라짐** (변환 자체가 없음). 남는 가열은 Q = 상류 운동량 remap 수치점성의 *부호 확정* 열. 매끄러운 w 에서 단위시간 Q ≈ ½ρu h(1−ν)(w')² (L0 와 같은 1차 크기), 노드 속도에 선형 재구성을 쓰면 갭이 O(h²) 로 감소할 것으로 *예상*(미증명). 즉 이제 가열은 *수치점성의 물리적 부호*이지 변환 오차가 아님.
**남음**: 노드 선형 재구성 remap 의 Q≥0 성립 여부(비단조라 보장 안 됨), H1 분기 선택, 이중 격자 계면 근처 (밀도 급변) 에서 M_f 가 작을 때 w 의 볼록결합 가중치 민감도.

## 18. 후속 8 (프롬프트 2): 상자 𝒦(p\*,q) 시간 팽창 Gronwall — LP-IMEX 불변성 (조건부)

**가설 H_G**: 계산 해에서 Stage L 의 셀 부피비가 |J_i−1| ≤ Gτ (이산 속도 기울기 한계 G). (에너지 선험 한계만으로는 |J−1|≤2τW/h 이라 1/h 가 붙어 무용. G 는 음향 정칙성 가정.)
**가설 H_T**: 모델 등엔트로피 경로 위에서 냉압력 평균 ≤ p (T≥0). 연속성(bootstrap)으로 경로 위 모든 J 에서 유지됨을 아래서 확인.

**Stage L 상자 변환.** 구간 J∈[J_-,J_+]=[1−Gτ,1+Gτ], Gτ≤1/2.
- z̄ 상한: z̄J^{−n} ≤ qJ_-^{−n} ≤ q·e^{2nGτ}.
- 압력 하한 (혼합 등엔트로피 ODE dp/dJ=−(1+Γ_m)p/J+Γ_mΣC_k(n_k−1)Z_kJ^{−n_k−1}):
 · 압축 J<1: C>0 항 ≤ Γ_m·(냉압력)/J ≤ Γ_m p/J (H_T) ⇒ p' ≤ −p/J ⇒ p(J) ≥ p0.
 · 팽창 J>1: C<0 항 ≥ −c_1p/J, c_1=Γ_m max_k((n_k−1−Γ_k)/Γ_k)₊ ⇒ p(J) ≥ p0J^{−κ_p}, κ_p=1+Γ_m+c_1.
 ⇒ p\*' ≥ p\*·e^{−κ_pGτ}. (단상은 정확식 p ≥ p0min(J^{−1−Γ},J^{−n}).)
- 하위 한계 r:=max_kA_kq_k/p\* 의 스텝 변화: r_{n+1} ≤ r_n·e^{(κ_p+2n_max)Gτ}.
- 연속성 논증: J 를 1 에서 경로 따라 움직이며 q_r=p−A z̄_rJ^{−n} 이 처음 0 이 되는 J 에서도 위 하한이 성립(등호) → 그 이전에 H_T 유지, 모순 없이 경로 전체 q_r>0 (r_{n+1}<1 인 한).
**Stage R**: T9 에서 상자 불변 (p\*,q 불변).
**정리 B (조건부).** H_G 하에 초기 r_0 =max_kA_k z̄_{k,max}/p_min 이 r_0·exp[(κ_p+2n_max)GT] ≤ 1 이면, 모든 n≤T/τ 에서 계산 상태가 상자 𝒦(p\*_n,q_n) 안: 모든 조각 θ_r>0, p≥p\*_n>0, Jensen 유지. 따라서 모멘트 수준 온도 양성이 **전체 LP-IMEX 스텝**(H1 + remap) 에서 유지.
- 의미: 팽창·압축의 *누적 로그 부피 변화 GT* 가 초기 열 여유 ln(1/r_0) 를 넘지 못하게 하는 조건. 지수 팽창 인자는 상자(분리 하한) 사용의 대가이며 정확 경로 자체의 한계가 아님.
- 한계: H_G 는 증명 안 된 가정 (재귀: w⁺ 기울기는 p 2차 차분에 의존). 일반 다상 H_T 는 위 연속성으로 상자 안에서만. 정리는 ‘조건부 정리’.

## 19. 후속 9 (프롬프트 3): KR 노름에서 평균 연산자 손실 h‖μ‖₁ 가 누적되는가 — 평형 단일 계면

설정 §11–§12 (u0>0, 한 계면, 위치차 e, L0 평평 상태).
**초기 차이 측도**: 물질1 ν₁=−b·1_{[X,X+e]}, 물질2 ν₂=+d·1_{[X,X+e]} (단일 부호 막대). KR(=BL) 노름 ‖ν‖_{BL}=sup{∫φdν:|φ|≤1,Lipφ≤1}: 단일 부호이면 =총질량 (폭 무관: φ=±1 이 폭 위 상수 가능). 즉 초기값 = be (L1과 동일).
**분해**: 스텝 후 ν_n = (막대 질량 −be, 이동·퍼짐) + 영질량 성분 η_n = P₊ − P₋, 총 양성 부분 P_n = Σ_k e θ_k(a−b)₊ (T8 에서 생성) = O(e ρ' uT ln(1/ν)).
 BL(ν_n) ≤ be + W₁-비용(η_n) ≤ be + P_n·d_n, d_n=P₊ 와 P₋ 의 평균 거리.
**거리 d_n**: 평균 L0 연산은 마르코프 핵 (볼록가중). 질량 입자(추적자)의 *공동 이동계* 변위: 평균 0 (평평 상태에서 중심 정확: 제1모멘트 νh 정확 이동), 스텝 분산 ≤ ν(1−ν)h² ⇒ n 스텝 후 분산 ≤ nν(1−ν)h² (독립 증분 — 평평 조각 내 균일 가정으로 마팅게일), 평균 이동 ≲ h√(nν(1−ν)) ≤ √(hTu(1−ν)) (n=Tu/(νh) 사용). 생성 위치는 계면 셀 내부(≤h).
 ⇒ d_n ≤ 2h + 2√(hTu).
**결과 (상계 개선 → §26-6)**: BL(ν_n) ≤ be + C·e·ρ'uT(ln(1/ν)+γ)·(h+√(hTu)).
 · 추가 항은 h→0 에서 **소멸** (O(√h)). L1 (§12) 의 선형 성장은 BL 에서 O(√h)로 감쇠.
 · "h‖μ‖₁ 손실이 스텝당 가산" 은 최악 상계 (N 스텝 ⇒ N h‖μ‖₁ = O(‖μ‖) 비소멸). 실제로는 비코히어런트 (√N·h). 이 구도에서 누적 안 됨.
**판정**: 이 구도(평형·한 계면·매끄러운 단일 물질 밀도·L0)에서 KR/BL 거리는 점근 비확대 (증가 항 O(√h), 점유율 무의존). **전체 정리는 아님**: 가정 (i) 평평 조각 내 균일 → 마팅게일 논증, (ii) 계면 셀에서 핵의 중심 정확성 추가 확인 필요, (iii) 여러 계면·재구성·가변 u 미처리.

## 20. 후속 10 (프롬프트 1): H_G 부트스트랩 — 소 τ 구간 유도와 한계

**결론 먼저**: 점별 H_G (|J−1|≤Gτ)를 비선형 계에서 *닫지 못함*. 선형·동결계수에서 *에너지 노름* 기울기 한계는 유도됨. 비선형 점별 부트스트랩은 도함수 손실 때문에 한 단계 높은 에너지(H²형)와 이산 소볼레프가 필요하고 그 교환자 추정은 이번에 전개하지 않음.

**G1 (동결계수; ⚠ 속도 단독 서술 정정 → §26-2).** 노드→셀 차분 D, K=diag(κ_i), κ_i=−∂p_i/∂J>0 (H_c), ŵ=M^{1/2}w, A=h⁻¹M^{−1/2}DᵀKDM^{−1/2}≥0 (대칭). 선형화 AVF 1스텝 (p̃_i=p_i^n−(κ_i/2h)ΔL_i, ΔL=τD(w⁻+w⁺)/2):
 (I+τ²A/4)ŵ⁺ = (I−τ²A/4)ŵ⁻ + τ b, b=M^{−1/2}Dᵀp^n (순수 압력 힘).
⇒ ‖(I+τ²A/4)⁻¹(I−τ²A/4)‖₂ ≤ 1, ‖(I+τ²A/4)⁻¹‖₂ ≤ 1 ⇒ **‖ŵ⁺‖ ≤ ‖ŵ⁻‖ + τ‖b‖, 모든 τ**. (음향 CFL 없음; 모드 θ=ωτ 에서 진폭: 암시 중점 =1, 명시 오일러 √(1+θ²), 후진 오일러 1/√(1+θ²).)
**G2 (기울기).** 노드 차분 D̃ 를 적용: ĝ=D̃w/h. 균일 격자·균일 계수면 D̃ 가 A 와 교환 ⇒ ĝ⁺=케일리(ĝ⁻)+τD̃b/h. 즉 기울기 에너지는 힘의 *2차 차분* S2=‖D̃b/h‖ 만큼만 스텝당 증가: ‖ĝ‖_{n+1} ≤ ‖ĝ‖_n + τS2.

**필요한 미증명 추정**: (E1) 교환자 |[D̃,M⁻¹κ]| ≲ h(|∇ρ|+|∇κ|) (E2) p̃−p 전개의 비선형 잔차 O(κ'|J−1|²) (E3) Stage R 의 기울기 영향: 볼록결합 가중치 변화 ∝ ∇F^d → 스텝당 (1+Cτ‖w_x‖_∞) (E4) 이산 소볼레프 상수의 h-균일성.

## 21. 후속 11 (프롬프트 2): 노드 선형 재구성 remap 에서 Q≥0 — 조건과 제한자

설정: 모든 이중 면 질량 flux F_i ≥ 0 (우향), 이중 셀 f 의 유입 F_in=F_i, 유출 F_out=F_{i+1}, ν_o=F_out/M_f, ν_i=F_i/M_{f−1}, M'=M−F_out+F_in. 선형 재구성: 하류 쪽 띠 평균 ŵ_out=w_f+½(1−ν_o)σ_f, 유입 ŵ_i=w_{f−1}+½(1−ν_i)σ_{f−1} (σ=셀 폭당 속도 변화, 셀평균 속도 w_f 보존 기울기).

**정확한 운동에너지 회계.** 새 셀 = (잔여 M_rem=M−F_out, 속도 ŵ_rem=(Mw_f−F_outŵ_out)/M_rem=w_f−½ν_oσ_f) ⊕ (유입 F_in, ŵ_i). 두 번의 분산 항등식:
 · 혼합: ½M'w'² = ½M_remŵ_rem²+½F_inŵ_i²−Q^{mix}, Q^{mix}=½M_remF_in/M'·(ŵ_rem−ŵ_i)².
 · 분할: ½Mw_f² = ½M_remŵ_rem²+½F_outŵ_out²−G, G=½M_remF_out/M·(ŵ_rem−ŵ_out)² = ½M_remF_out/M·σ_f²/4 (ŵ_rem−ŵ_out=−σ_f/2, ν_o 무관).
 합: ½M'w'² = ½Mw_f² − ½F_outŵ_out² + ½F_inŵ_i² + G − Q^{mix}. 이중 면의 ½Fŵ² 항은 인접 셀에서 상쇄(망원) ⇒
 **ΣKE_new = ΣKE_old + ΣG − ΣQ^{mix}, 총 가열 = Σ(Q^{mix}−G)**. (1차: ŵ=w ⇒ G=0, 앞서의 Q 와 일치.)
**국소 조건 Q_f:=Q^{mix}_f−G_f ≥ 0** ⇔ (F_in/M')(Δ_f−½ν_oσ_f−½(1−ν_i)σ_{f−1})² ≥ (F_out/M)σ_f²/4, Δ_f=w_f−w_{f−1}.

**정리 Q.** (i) 일정 ν (ν_i=ν_o, M'=M): minmod 기울기 σ_f=minmod(Δ_f,Δ_{f+1}) 는 Q_f≥0. 증명: Δ_f>0 이면 0≤σ_f,σ_{f−1}≤Δ_f ⇒ 좌변 괄호 ≥ Δ_f−½νΔ_f−½(1−ν)Δ_f=Δ_f/2 ≥ σ_f/2 ⇒ 조건. Δ_f≤0 대칭. σ_f=0 이면 자명. ∎
(ii) 일반 (ν_i≠ν_o, M'≠M): 괄호 ≥ Δ_f(1+ν_i−ν_o)/2 ⇒ 충분조건 σ_f ≤ Δ_f(1+ν_i−ν_o)√(F_inM/(F_outM')). **제한자**: σ_f = minmod(Δ_f,Δ_{f+1})·min{1, (1+ν_i−ν_o)√(F_inM/(F_outM'))}. (1+ν_i−ν_o>0 since ν_o<1.) 계수 감소는 좌우 모두 단조로 안전.
(iii) 균일 w: Δ=0, σ=0 ⇒ Q=0 (PE 유지).
**근거 구조 (철회 → §26-5)**: KE_new(φ) 는 슬로프 계수 φ 에 대해 2차식 ⇒ Q(φ)=Q(0)−bφ−cφ², c≥0 ⇒ {Q≥0} 는 φ=0 을 포함하는 구간 — 따라서 제한자의 존재는 구조적으로 보장되고, 위 식은 국소 명시형.
**미증명/남음**: 우향·좌향 혼재 F 부호 (사례 분석 미작성), 밀도 급변에서 ν 비율 극단 (제한자가 σ→0, 1차 퇴화), 2차 정확도 보존 (minmod 극값에서 1차).
**가열의 크기**: 제한자가 비활성 구간에서 Q = Q^{mix}−G = O(h⁴)(σ,Δ 일관) 로 감소 예상 — 2차 소산 (엄밀한 크기 추정은 미작성).

## 23. 약점 보완 1: 평형 구간 수렴 정리 — 요구한 재귀 구조를 *이 구간에서* 닫음

**설정.** 균일 u0>0, p0. 정확해: 물질별 강도량 g ∈ {ρ_k, ρ_kⁿ} 이 계면 사이에서 C², 계면 N_I 개 (유한), 평행이동. 수치: L0 (§3) + 덧셈 합집합, ν=u0τ/h ∈ (0,1]. Π: 정확해를 L0 상태로 사영 (조각 = 정확 계면 ∩ 셀, 내용 = 정확 적분).
오차 e_n := Σ_{필드,조각} |내용(U_n) − 내용(ΠU(t_n))| (= 같은 분할 위 조각상수 함수의 L1).

**보조정리 (계면 위치 정확).** L0 에서 계면은 정확히 u0τ 이동 → 수치·사영 상태가 같은 분할을 공유. ∎

**정리 CV.** 모든 N≤T/τ 에서
 e_N ≤ e_0 + T·u0·[ (1−ν)h/2 · ‖g''‖_{h,1} + c_0 N_I h ‖g'‖_∞ ],
 ‖g''‖_{h,1}:=Σ_c h·max_{I_{c−1}∪I_c}|g''|, c_0 ≤ 6 (계면 인접 조각·띠 쌍 수 상계). 상수는 **점유율 무관**, 지수 증폭 없음 (재귀 상수 C=0), 병합 오차 b_n=0 (근사 병합 없음).
**증명.**
(1) 안정성: e_{n+1} ≤ ‖TU_n−TΠU(t_n)‖ + ‖TΠU(t_n)−ΠU(t_{n+1})‖. 같은 분할에서 T 는 내용 벡터에 대한 *선형·양·열합 1* 사상(새 조각 내용 = Σ 기하 비율 × 옛 조각 내용) ⇒ 첫 항 ≤ e_n.
(2) 내부 국소오차 (계면 없는 셀): 오차 범함수 L(g)=(1−ν)∫_{I_c}g+ν∫_{I_{c−1}}g−∫_{I_c−δ}g. L(1)=L(x)=0 (직접 계산), L(x²/2)=ν(1−ν)h³/2. Peano 핵 K(t)=L((x−t)₊) ≥ 0: 혼합 밀도 (ν/h on I_{c−1}, (1−ν)/h on I_c) 와 균일 U[−δ,h−δ] 의 밀도차 부호가 +,−,+ 이고 평균이 같음 → Karlin–Novikoff 절단 기준으로 볼록 순서 ⇒ 볼록 함수에 L≥0 ⇒ K≥0. 따라서 |L(g)| ≤ ν(1−ν)h³/2 · max|g''|.
(3) 계면 인접: 띠 S⊂옛 조각 Q 마다 |S|·|mean_Q g − mean_S g| ≤ δ·h·‖g'‖_∞. 스텝당 그런 쌍 ≤ c_0N_I.
(4) 합: L_n ≤ ν(1−ν)h²/2·‖g''‖_{h,1} + c_0N_I νh²‖g'‖_∞. N=Tu0/(νh) 스텝 합산. ∎
**따름정리.** 같은 구간에서 p≡p0, u≡u0 정확 (T3), 총에너지 정확 (T2), 계면 위치 오차 0 → **계면 위치: 정확, 물리 L1: 1차, 안정성 상수: 1 (점유율 무관)**.
**정직한 평가.** 이 구간은 선형 수송으로 환원되므로 정리 자체는 1차 상류 수렴의 다물질·Z 확장 (기법은 표준). 기여는 "비선형 MG + 독립 Z + 정확 PE + 소 점유" 를 동시에 담은 첫 *완결* 재귀라는 점뿐. 2차 (제한 재구성) 와 비평형 구간은 여전히 미증명.

## 24. 약점 보완 2: 정리 Q 의 부호 혼재 확장

이중 셀 f 의 두 이중 면 flux (F_i 좌, F_{i+1} 우; 양수=우향). 정의 Q_f := Q^{mix}_f − G_f (G_f = f 자신의 유출 분할 갭).
- (a) F_i≥0≥… 우향 단조 (F_i≥0,F_{i+1}≥0): §21 정리 Q. (b) 좌향 단조: 거울.
- (c) **수렴** (F_i≥0, F_{i+1}≤0, 양쪽 유입): f 는 유출 없음 ⇒ G_f=0, 새 셀 = 원래 ⊕ 두 유입 조각 혼합 ⇒ Q_f=Q^{mix}_f (3 조각 분산) ≥ 0. **임의 재구성에서 성립**. f 의 기울기는 쓰이지 않음.
- (d) **발산** (F_i≤0, F_{i+1}≥0, 양쪽 유출): 유입 없음 ⇒ Q^{mix}_f=0, 분할은 (좌유출, 잔여, 우유출) 3 조각 ⇒ G_f = 3 조각 분산 > 0 (σ_f≠0 이면) ⇒ **Q_f<0**. 반례: 선형 프로파일, 대칭 발산 ⇒ 두 끝 띠 평균이 w_f±σ(1−ν)/2 ⇒ G>0.
 **필수 규칙**: 발산 이중 셀에서 σ_f=0. 그러면 모든 조각 속도=w_f, G=0.
**정리 Q′.** 기울기 규칙 {단조: §21 제한자; 수렴: 자유; 발산: σ=0} 하에 모든 이중 셀에서 Q_f≥0, 총에너지 정확 보존, 균일 w 에서 Q=0. ∎
**대가**: 발산 노드(국소 팽창)에서 1차 퇴화 → 2차 정확도가 팽창 영역에서 깨질 수 있음. 전역 회계(인접 Q^{mix} 로 G 상쇄)로 완화 가능하나 국소 열 음수가 생김 — 채택 안 함.

## 26. 독립 검토 반영 (정정·철회)

독립 검토(읽기·손계산만, 별도 에이전트)의 지적을 내가 재검산 후 반영. 대부분 대수는 통과 (§1.4, §11–12, §13, §17 항등식, §18, §21 정리 Q).

**26-1 [중대] H_c 는 혼합상 일부에서 *거짓*.** 혼합 등엔트로피 p(J)J^{1+Γ_m} = p0 + Γ_mΣ_kC_k(n_k−1)Z_k(J^{Γ_m−n_k+1}−1)/(Γ_m−n_k+1). C_k>0 이고 n_k−1>Γ_m 이면 J→0 에서 해당 항 → −∞ ⇒ p→−∞, I 하한 없음. (n_k−1=Γ_m 로그 경우도 C_k>0 이면 −∞.) 예: 상1 n=3, Γ=3 (C>0), 상2 Γ=0.4, α=½ ⇒ Γ_m≈0.71 < 2. 재검산 확인.
 ⇒ **H1 의 적용 조건**: 모든 k 에 대해 C_k>0 ⇒ n_k−1 < Γ_m (+ 볼록성). 이 범위 밖에서는 α 고정(Allaire) 등엔트로피 압축이 *모델 압력을 음으로* 만든다 — 수치법 문제가 아니라 닫힘 자체의 성질 (Kapila 보정 없는 isobaric 혼합). 이 범위 밖의 큰 dt 존재는 **불가 구간 포함**으로 재분류.

**26-2 [중대] §20 G1 정정.** 속도 단독 사상 (I+τ²A/4)⁻¹(I−τ²A/4) 은 고유값 (1−λτ²/4)/(1+λτ²/4) ∈ (−1,1] 인 *축약*이지 등척 아님. 또 b 가 진화하는 p 에 의존하므로 ‖ŵ⁺‖≤‖ŵ⁻‖+τ‖b‖ 는 닫히지 않음. **올바른 진술**: 동결계수 선형 (w,p) 계에서 중점법은 ½‖ŵ‖² + (h/2)⟨δp, K⁻¹δp⟩ 를 정확히 보존 (쌍 (w,p) 의 케일리 등척). §20 의 결론("선형에서 에너지 노름 한계")은 이 쌍 에너지로 읽어야 함.

**26-3 [경미] §1.2.** n≠2 격차는 섭동에 대해 1차(부호 부정)이나, 매끄러운 r 에서는 ‖(I−Π)r_h^{n−1}‖ 과 ‖r−r_h‖ 이 같은 h-차수 → n=2 제곱항과 *같은 격자 차수*. "n=2 보다 크다" 철회. r_h 상수면 0.

**26-4 [경미] 엄격 부등식.** T9: θ>0 (𝒜 소속) 을 위해 A_kq_k < p\*. 정리 B: r_0·exp[(κ_p+2n_max)GT] < 1. T3 의 "분기 유일" 은 소 τ (IFT) 한정, 큰 τ 는 분기 선택 가정 필요.

**26-5 [철회] §21 "근거 구조".** φ² 계수 부호 부정 (c≥0 무근거), Q(0)=0 이면 φ=0 만 남을 수도 있음 → 문단 철회. 명시 제한자 (정리 Q(ii)) 로 충분. 추가 확인: minmod 에서 매끄러운 w 의 가열 O(h³)M/셀/스텝 = O(h²) 율 (2차 소산); 무제한 중앙 기울기는 Q<0 가능.

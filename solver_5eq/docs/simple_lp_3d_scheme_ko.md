# 3D 용 단순 다물질 스킴 (명시적 릴랙세이션 면유속 + 상류 수송), 2026-10-23

대상: `solver_5eq/results/lp_imex_moment/simple_lp.py` (1D), `simple_lp_nd.py` (1D/2D/3D). 목적은 오차보다 **알고리즘의 단순함과 계산 부하** 이다. 계면 적합 Lagrange–remap (`fitted_scheme.py`) 은 3D 에서 메시 얽힘, 다각형 remap, 절단 셀 처리가 필요해서 이 스킴으로 대체한다. 이 스킴은 새로운 방법이 아니라 알려진 구성 요소의 단순한 조합이다 (Allaire 5방정식 + 음향 릴랙세이션/AUSM 꼴 면유속 + THINC). 새로움은 주장하지 않는다.

## 1. 알고리즘 (전부)
변수 (셀마다): m₀ = α₀ρ₀, m₁ = α₁ρ₁, 운동량 q (d 성분), 전체 에너지 E (여기까지 보존), α = α₀ (같은 면속도로 수송).
EOS (상마다): e_k = p/Γ_k + C_k ρ_k^{n_k}, C_k = A_k(1/(n_k−1) − 1/Γ_k) (기존과 같은 멱법칙 Mie–Grüneisen).

1. **압력 닫힘 (반복 없음).** EOS 가 p 에 선형이라 압력 평형 닫힘이 닫힌 식이다:
   ρ_k = m_k/α_k, p = (E − ½ q·q/ρ − Σ α_k C_k ρ_k^{n_k}) / (Σ α_k/Γ_k).
2. **면 해 (면마다, 면 법선 방향).** a = κ·max((ρc)_L, (ρc)_R) (κ=1.5, Wood 혼합 음속: 1/K = Σ α_k/K_k, K_k = n A ρ_k^n + (1+Γ)(p − Aρ_k^n)),
   u* = ½(u_L+u_R) − (p_R−p_L)/(2a), p* = ½(p_L+p_R) − ½ a (u_R−u_L).
3. **플럭스.** 면 속도 u* 의 부호로 상류 상태 s 를 고른다:
   F_{m_k} = u* m_k^s, F_q = u* q^s + p* n̂ (접선 운동량은 u* q_t^s), F_E = u* E^s + p* u*.
4. **α 방정식 (비보존형).** α_t = −Σ_축 [u*_r α^s_r − u*_l α^s_l − α(u*_r − u*_l)]/Δx.
5. **갱신.** 1차: 전진 오일러 (CFL ≈ 0.4/차원 보정). 2차: 원시 변수 (α, ρ₀, ρ₁, u, p) 의 minmod 재구성 (α 는 THINC, β=1.6) + SSP-RK2.
암시적 풀이, 뉴턴 반복, 기하 (절단 셀, 격자 이동, 조각) 가 전혀 없다. 3D 는 면 플럭스를 세 축에서 더하기만 하면 된다 (`simple_lp_nd.py` 가 d 에 무관하게 같은 코드).

## 2. 성질 (시험으로 확인, 증명은 일부)
- **균일 압력·속도 평형 보존 (비선형 EOS 포함).** 모든 상의 ρ_k 가 상별로 균일하면 u*=u, p*=p 이고 m_k, α, E 가 같은 가중으로 섞이므로 E 가 α 에 선형이라 p 가 그대로이다 (대수적 증명). 이동하는 물|기체 계면 (1D, 2200–3000 스텝), 이동하는 원 (2D), 이동하는 구 (3D, 1060 스텝) 에서 |p−10| ≲ 2e-14, |속도 오차| ≲ 3e-14.
- **정확한 보존.** 질량·운동량·총에너지가 플럭스 형태 (주기 경계) 라서 반올림 수준 (1D 충격관 ≤ 5e-16, 2D 충돌 ≤ 8e-16, 3D 이동 구 0.0).
- **α ∈ [0,1].** 비보존 갱신이 상류 볼록 결합이 되어 (CFL 조건에서) α 가 구간을 벗어나지 않는다 (`clip` 은 반올림 안전장치; 시험에서 α 는 [0, 1] 안에 있었다).
- **상 밀도 양성.** ρ_k = m_k/α_k 는 이웃 값의 가중평균 (mediant 부등식) 이다. 열 에너지 (e_k − C_kρ_k^n) 양성은 시험에서 확인했을 뿐 증명하지 않았다.
- **점유 0 ↔ 양수.** α 가 0 에서 양수로 바뀌는 것을 특별 처리 없이 (α < 1e-9 이면 기준 밀도 사용) 지난다.

- **계면 번짐.** THINC 가 없으면 이동하는 계면의 두께가 시간에 따라 커진다 (N=200, 계면 하나당 19 → 27 셀, 격자 이동 70 셀 동안). THINC 로 계면당 4 셀로 고정된다 (시간, 시험한 기간 안에서).
- 1차는 매우 단순하고 견고하지만 계면과 충격이 심하게 번진다 (L¹ 이 2차의 3–4 배).

## 4. 3D 로의 확장과 비용
- 구조: 면마다 위의 3 단계를 면 법선 방향으로 적용하고 합산한다. 2D 충격-물기둥 (256², 2차) 에서 α ∈ [0,1], 최소 압력 9.93, 보존 1e-16, 그림 `simple_lp_2d.png` 에서 반사파·투과파·물기둥 변형이 합리적이다.
- 한 셀의 연산량 (대략): 원시 변수 복원 약 25 flop (정수 멱은 곱셈), 면마다 음향 속도 + 면 해 + 플럭스 약 100 flop, 3D 1차 약 500 flop/셀-스텝, 2차 (재구성 + RK2 의 두 번 평가) 는 그 3–4 배.
- **측정 (NumPy 벡터화, 한 스레드, 셀-스텝당):** 1D 0.35 µs (1차) / 0.99 µs (2차), 2D 0.63 / 1.9 µs, 3D 0.91 / 3.7 µs. NumPy 는 임시 배열 때문에 C++ 보다 몇 배 느리므로 절대값은 참고용이다.
- **계면 적합 스킴과의 비교 (같은 언어가 아님에 유의).** 계면 적합 오라클은 순수 파이썬 루프로 N=200 에서 0.89 ms, N=800 에서 0.74 ms 가 영역-스텝당 든다 (매 스텝 뉴턴 반복 80 회 상한을 항상 채운다: 허용오차 1e-14 에 도달하지 못한다). 단순 스킴의 1–4 µs 와 약 200–700 배 차이가 나지만, 이는 언어 차이가 대부분이고 알고리즘 비용 비율이 아니다. 알고리즘 차이로는 뉴턴 반복 (영역마다 비정수 지수 거듭제곱을 포함하는 할선 압력과 에너지 평가를 반복) 과 remap 의 조각 적분 (조각 수가 계면 근방에서 늘어남) 이 사라진 것이 핵심이고, 대략 10 배 이상 적다고 본다 (측정하지 않았다).

## 5. 잃은 것 (정직하게)
- **계면이 번진다** (THINC 로 셀 4 개). 계면 위치 2차, 계면 적합의 정확한 보존 (물질별 질량이 계면을 넘지 않음) 은 없다. 물질 질량 m_k 는 보존되지만 계면 셀에서 두 물질이 섞인다.
- **독립 모멘트 Z, 점유율 무관 안정성 상수, 완전 이산 총에너지 증명의 이론은 이 스킴에 적용되지 않는다.** 대신 CFL 이 음속 기반이라 저마하에서 시간 간격이 작다 (c ≫ u 일 때 계면 적합 LP-IMEX 의 큰 시간 간격 이점은 없다).
- 열 에너지 양성, 극한 희박파 (진공 근처) 에서의 강건성은 증명하지 않았고 시험도 제한적이다 (압력비 15 까지).
- 2차는 minmod 재구성의 일반적 한계 (극값에서 차수 저하) 를 가진다.
- 물|기체 한 EOS 쌍 (같은 EOS 형식), 주기 경계만 시험했다. 3D 는 이동 구의 압력 평형·보존만 시험했고 3D 충격 문제는 시험하지 않았다.

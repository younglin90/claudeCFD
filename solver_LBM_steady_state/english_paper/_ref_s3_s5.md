## §3 Benchmark Suite and Evaluation Protocol (reorganize the setup material now misplaced under "4. Results")

The suite comprises nine flow families, evaluated at three mesh levels (1x/2x/3x), for 27 proposed-method runs in total. Families and roles: plane Poiseuille and Couette (analytic references); lid-driven cavity at Re = 100/400/1000 (Ghia centerline literature benchmark); backward-facing step and cylinder wake (separation, reattachment, wake); multi-cylinder (complex mask boundary); T-junction (branching geometry with inlet/outlet coupling). Keep the existing benchmark-family table (grid sizes, boundary conditions, role, reference tier) as a clean pipe table in §3.

Convergence is judged on the macroscopic L2 change of the pressure and velocity fields, not the microscopic f-RMS. The pressure increment is made gauge-invariant by removing its fluid-domain mean (the absolute pressure / density-mean level is an arbitrary constant in weakly compressible closed or periodic flow); component L2 norms are taken over fluid nodes only. Final convergence requires the simultaneous satisfaction of: (i) absolute residual r_macro <= 5*tau; (ii) a plateau condition (fractional improvement over the most recent window W=50 at most eta=0.05, i.e. the decrease has reached the numerical floor); and (iii) physical admissibility (density positivity, finite fields, boundary/mask consistency). The base tolerance tau is 1e-7 for the non-cavity families and 1e-8 for the cavity families at 1x, tightened by 1/2 and 1/3 at 2x and 3x. These constants and the admissibility rule are applied identically to the proposed method and all baselines, with no per-case tuning.

Five baselines share the same native LBM operator of the same code base: native LBE (collide–stream–boundary fixed-point / Picard iteration), Anderson acceleration (depth m=10, beta=1.0, regularization 1e-12), preconditioned LBM (balanced PLBE gamma=0.5), inexact Newton–Krylov (JFNK: GMRES krylov_max=10, with smoother and line search), and dual-time multigrid (FAS V-cycle, max_levels=6). Each receives literature-standard hyperparameters and a generous budget (about 6e5–1.2e6 LBE-calls for cavity 2x/3x); none is deliberately weakened. The only difference between the proposed method and a baseline is the update rule. All run in the same Python/NumPy environment calling the same native operator, so wall-time differences reflect algorithmic structure, not language/library.

Comparison metric: because methods stop at different accuracies, all methods are compared by time-to-threshold — the cost to first reach a common target residual epsilon. The cost is read both as wall time and as the number of native operator evaluations G(f) (LBE-call), the latter being a hardware-independent, fully deterministic operator-work metric that includes the cost of rejected correction trials. Reference solutions (analytic, Ghia, tight numerical) are used only for post-solve accuracy evaluation, never inside the solve; accuracy is the relative L2 error against the reference. The proposed method solves all 27 problems with a single deterministic routine; only the problem definition (grid, Re, boundary, mask) changes per case.

## §5 Discussion (create; concise; NO defensive tables)

Mechanistic interpretation. The performance gain follows from the Schur-complement structure of the steady residual. Native collide–stream relaxation damps the kinetic block J_kk locally and quickly, but acts only weakly on the global hydrodynamic coupling carried by the moment Schur complement S_m, whose near-unity damping factor produces the long convergence plateau. The AP-Schur preconditioner applies an analytic approximation of S_m^{-1} restricted to the conserved-moment subspace, removing precisely this slow component, so the residual continues to descend where native iteration stalls. The ablation (AP-Schur-only attains the lowest total time and full convergence breadth) and the non-trivial correction-acceptance rate across all cases support this interpretation. The local linear analysis guarantees only a reduced amplification factor of the captured slow mode; because the admissibility gate falls back to the native step on failure, the approximate nature of the preconditioner affects speed but not the converged solution.

Limitations and scope. The scope is the 2D D2Q9/BGK steady benchmark suite; no direct claim is made for 3D, thermal/compressible LBM, MRT/entropic collisions, or high-Reynolds turbulence. The accuracy evidence (second order for Poiseuille, machine precision for Couette, monotone approach to Ghia) is code verification for cases with closed-form/literature references, not a formal grid-convergence (Richardson/GCI) study for every geometry; no formal order is claimed for the tight-reference cases. The method does not remove discretization or boundary-condition error — the nonzero Ghia error is a direct example — it reaches the same discrete steady solution faster. Wall time depends on CPU, memory bandwidth, and library implementation and is therefore interpreted as a relative metric within one result set; the operator-work (LBE-call) metric, which is deterministic, complements it. On problems where the global slow mode is weak (simple shear) or where boundary-driven local modes dominate, the per-iteration cost of the correction is not amortized and the net speedup is small or negative; this exception is consistent with — and predicted by — the same slow-mode-dominance mechanism.

Future work. Shortening the near-stagnation phase before the terminal Newton collapse (adaptive inner-Krylov dimension and inner tolerance), extension to 3D, MRT/entropic collision models and higher Reynolds numbers, and a quantitative open-boundary flux-closure bound.

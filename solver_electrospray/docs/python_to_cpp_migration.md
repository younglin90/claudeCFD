# Python to C++ Migration Ledger

This repository is now primarily driven by the CMake/C++ FVM solver path. The
remaining Python tree is a legacy validation, reporting, plotting, and reduced
model layer.

## Completed in C++

- `validation_manifest.py`: C++ manifest structs and required-case coverage in
  `include/electrospray/Validation.hpp`.
- `validation_report.py`: JSON and Markdown validation summaries in
  `include/electrospray/Validation.hpp`.
- `validation_cli.py`: C++ replacement executable
  `electrospray_validation_cli`; the C++ CLI now accepts the former Python
  artifact formats and check flags used by validation/report automation.
- `validation_artifacts.py`: retired after moving artifact status checks to
  the C++ CLI/CTest path. The C++ guard checks persisted Markdown/JSON
  artifacts and PNG signatures; it does not regenerate every legacy manuscript
  table/figure from Python formulas.
- `manuscript_figures.py`, `manuscript_tables.py`, `field_contours.py`, and
  `submission_readiness.py`: retired as Python artifact generators. Their
  persisted Markdown/JSON/PNG outputs are now guarded by
  `electrospray_validation_cli --check-all-artifacts`; live regeneration of
  those manuscript convenience artifacts is intentionally no longer part of the
  Python path.
- `full_cfd_readiness.py`: retired as a Python readiness-report generator; the
  persisted readiness JSON/Markdown artifacts are now guarded by the C++ CLI.
- `validation_runner.py` and `validation_cases_full_cfd.py`: retired as Python
  validation aggregation wrappers. Core validation summary, required-case
  coverage, full-CFD readiness artifacts, and executable solver gates are now
  covered by C++ CLI/CTest targets.
- `validation_cases_*.py`, `validation_coverage.py`, and
  `validation_report.py`: retired the remaining Python validation wrapper
  layer. The authoritative validation surface is now
  `cmake --build build && ctest --test-dir build --output-on-failure` plus the
  C++ validation executables.
- `propellant.py`, `microthruster.py`, `thruster_design.py`,
  `plume_particles.py`, `plume_tracking.py`, and
  `spacecraft_impingement.py`: ported reduced application/plume/thruster
  algebra to `include/electrospray/ApplicationModels.hpp` with
  `test_electrospray_application_models`.
- `droplet_stability.py`, `regime_map.py`, `validation_manifest.py`,
  `timestep.py`, `emitter_array.py`, `electrical_diagnostics.py`,
  `interface_electrics.py`, and `cone_geometry.py`: ported or retired after
  equivalent C++ scalar/diagnostic checks were added to
  `Validation.hpp`, `MaterialProperties.hpp`, and `Diagnostics.hpp`.
- `coupled_step1d.py`, `projection1d.py`, `vof_transport.py`, and
  `electrospray1d.py`: retired the orphaned Python 1D reduced-step stack after
  the corresponding electrostatic, VOF, charge-relaxation, and scalar checks
  were covered by the C++ validation suite.
- `external_benchmarks.py`, `benchmark_stepper_observables.py`, and the legacy
  Python 2D/axisymmetric reduced solver chain
  (`axisymmetric_*`, `coupled_step2d.py`, `full_cfd_solver.py`,
  `electrospray2d.py`, `projection2d.py`, `state.py`, and scalar helpers):
  retired after becoming orphaned. The persisted benchmark/readiness artifacts
  remain guarded by C++ artifact checks, while executable solver regression is
  carried by the C++ FVM tests.
- `ehd3d.py`, `fvm_mesh.py`, `material_properties.py`,
  `production_cases_3d.py`, the remaining `results/*.py` production/plotting
  runners, and `generate_korean_sci_manuscript_docx.py`: retired the final
  Python production/document-generation path. The repository's executable
  solver and validation surface is now C++/CMake/CTest only; persisted
  historical CSV/PNG/DOC artifacts are retained as data, not regenerated by
  Python.
- `verify_electrospray.py`: C++ replacement executable
  `verify_electrospray_cpp`.
- `electrospray1d.py` 1D electrostatic validation subset: C++ tridiagonal
  finite-volume electrostatic solve and dielectric-jump checks.
- `charge_relaxation_time.py` validation subset: exact and backward-Euler
  relaxation checks.
- `vof_transport.py`/`charge_transport.py` validation subset: bounded 1D VOF
  update, charge confinement, and gas-leakage metric.
- `capillary.py` validation subset: Laplace pressure and CSF force checks.
- `droplet_stability.py`: Rayleigh limit, fissility, and threshold checks.
- `regime_map.py`: reduced cone-jet regime classification checks.
- `cone_geometry.py` validation subset: Taylor cone angle, level set, fit,
  force balance, and voltage-ramp checks.
- `emitter_array.py`: reduced multi-emitter current and shielding checks.
- `__init__.py`: retired the Python package-wide re-export façade; no in-repo
  validation or CMake target imports the package API, and the supported
  validation entry points are now C++ executables.
- `validation_cases_3d.py`: retired as a Python leaf; the 3D electrostatics,
  EHD coupling, PLIC/VoF, pressure-velocity, and adversarial mesh checks are
  now covered by dedicated CTest targets.
